# ENFILADE 모드 폴더

이 폴더에 넣은 모드는 게임을 켤 때 읽힌다. Unity도, 다시 빌드할 필요도 없다. 메모장이나 엑셀로 CSV 표를 고치면 된다.

- 게임(빌드)에서는 실행 파일 옆의 `Mods` 폴더, Unity 편집기에서는 프로젝트 맨 위의 이 폴더를 읽는다.
- 자세한 설명과 표 목록은 [모드 만들기](../Docs/Modding.md)에 있다.

## 모드 하나의 모양

```
Mods/
  내모드/                  폴더 하나가 모드 하나. 폴더 이름 순서로 읽고, 뒤에 읽은 모드가 이긴다
    mod.txt               (선택) 모드 설명 한 줄. 콘솔 /mods에 나온다
    Tables/Weapons.csv    게임의 표와 같은 이름의 CSV. 하위 폴더는 마음대로 나눠도 된다
  _Example/               이름이 _ 나 . 으로 시작하는 폴더는 읽지 않는다 (꺼 두기)
```

## 표를 고치는 규칙

1. 게임 콘솔(`` ` `` 키)에서 `/mods export` 를 치면 게임의 원래 표가 `Mods/_게임 원본/Tables` 에 나온다.
2. 고치고 싶은 표만 내 모드의 `Tables` 폴더에 복사한다. **고칠 줄과 고칠 칸만 남겨도 된다.**
   - 첫 줄(머리글)은 칸 이름이다. 첫 칸은 줄의 이름(`id`)이다.
   - 게임에 있는 `id` 의 줄은 **채워 넣은 칸만** 바뀌고, 비운 칸은 게임 값 그대로다.
   - 게임에 없는 `id` 는 새 줄로 더해진다(새 무기 줄, 새 상점 물건, 새 글자).
   - `#` 으로 시작하는 줄과 칸은 설명이라 게임이 읽지 않는다.
3. 파일은 **UTF-8** 로 저장한다(엑셀: "CSV UTF-8(쉼표로 분리)").
4. 게임을 다시 켜거나 콘솔에서 `/mods reload` 를 친다. `/mods` 는 지금 읽힌 모드를 보여 준다.

## 알아 둘 것

- 같이 하는 사람은 모두 같은 모드를 넣는다. 숫자 대부분은 방장이 정하지만 화면은 각자 자기 표로 그린다.
- 화면 글자도 표다(`Texts.csv`). `en` 칸을 채우면 번역판이 된다.
- 새 모델·맵·옷·총 모양처럼 표로 안 되는 것은 Unity 프로젝트를 열어서 넣는다. 순서는 [모드 만들기](../Docs/Modding.md)에 있다.
