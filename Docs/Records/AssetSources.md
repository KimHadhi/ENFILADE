# 외부 에셋 출처

[프로젝트 안내](../../README.md) · [애드온 이식 기록](AddonPortNotes.md) · [설정·유지보수](../Guides/MaintenanceGuide.md)

프로젝트에 들어온 외부 에셋의 출처를 모은 목록이다. 나중에 무엇을 빼거나 바꿀지 확인하는 용도이고, 크레딧이 아니다. 지금 들어간 다른 게임과 애드온의 에셋은 분위기를 잡기 위한 임시 자료이며, 직접 만든 에셋이 생기면 바꾼다.

**새 외부 에셋을 넣으면 같은 작업에서 이 문서에 한 줄을 추가한다.** 워크숍 에셋은 워크숍 번호를 함께 적는다. 경로는 `Assets/_Project` 기준이고, `Assets/`로 시작하는 경로만 프로젝트 밖의 팩이다. 파일 수와 크기는 2026-11-01에 잰 값이다.

## 0.9.0에서 정리한 것 (2026-11-13)

게임이 닿지 않는 것을 지웠다(에셋의 GUID 참조와 코드·표·도구에 적힌 경로를 모두 따라가 확인). 아래 표들의 개수와 크기는 들여올 때의 값이다.

| 팩 | 한 일 |
| --- | --- |
| `Assets/RVFX/RVFXDestructionSystem` | 통째로 지움. 게임이 쓴 적이 없다 |
| `Assets/ThirdParty/LowPolyWeaponBundlePackV` | 탄약 줍기 모델인 탄약 상자 `AmmoCase_A`(프리팹·모델·재질·그림)만 남김 |
| `Assets/ThirdParty/AdvancedZombieAIPro` | 좀비 모습이 쓰는 클립 7개(`DemoScene/Assets/Animations (Representational)/Animations`)만 남김. 스크립트를 지웠으므로 아래 `ZombieSpawner.cs` 수정 줄은 지난 일이다 |
| `Assets/ThirdParty/JMO Assets` | `Demo Assets`, `Welcome Screen`, 데모 씬, 옛 효과 unitypackage를 지움. `CFXR Assets`와 `CFXR Prefabs`는 그대로 |
| `Assets/ThirdParty/DAVFX` | 데모 씬과 데모 스크립트, HDRP unitypackage를 지움 |
| `Assets/ThirdParty/Vefects` | `Demo`, `2D URP`, `Documentation`을 지움 |
| `Assets/ThirdParty/MagicaCloth2` | `Example (Can be deleted)`를 지움 (git 밖이었다) |

되돌리려면 `git checkout pre-0.9.0 -- "<경로>"`. MagicaCloth2 예제는 git에 없었으므로 Asset Store 패키지에서 다시 들인다.
