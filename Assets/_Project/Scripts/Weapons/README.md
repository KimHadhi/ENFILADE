# Weapons — 총

총의 규칙과 손에 든 총이다. 탄약·발사·조준 규칙(Core), 쏠 때의 효과(Effects), 손에 든 총과 부착물(FPSBody, KINEMATION)

전체 지도는 [스크립트 길잡이](../README.md), 프로젝트 구조는 [구조 안내](../../../../Docs/Architecture.md)에 있다.
