# Weapons — 총

총의 규칙과 손에 든 총이다. 탄약·발사·조준 규칙(Core), 쏠 때의 효과(Effects), 손에 든 총과 부착물(FPSBody, KINEMATION)

전체 지도는 [스크립트 길잡이](../README.md), 프로젝트 구조는 [구조 안내](../../../../Docs/Architecture.md)에 있다.

## 폴더

| 폴더 | 스크립트 | 무엇 |
| --- | ---: | --- |
| [Core](Core/) | 14 | 무기 데이터와 발사·조준·반동 규칙, 총이라는 물건과 예비 탄약, 장전의 순간과 장전된 뒤 남은 동작을 끊는 규칙([ReloadRules](Core/ReloadRules.cs), `ReloadRules.csv`), 탄약 기록과 탄약 규칙 점검(플레이 없는 점검을 스크립트를 읽을 때마다 돌리는 [CheckOnRequest](Core/CheckOnRequest.cs)) |
| [Effects](Effects/) | 10 | 총구 화염과 총마다의 모습, 예광탄, 탄착, 쏠 때의 손맛 |
