# Modes — 게임 방식

허브(사격장·결과 연출)와 모드가 함께 쓰는 것. 모드(판의 규칙)는 제 폴더에 두고 게임은 모드의 이름을 부르지 않는다: 죽음·부활·난입 규칙은 [RunRules](../Player/Life/RunRules.cs)에 `Begin`으로 등록하고 끝날 때 `End`, 이야기 카드와 [F] 안내는 [ModeScreen](ModeScreen.cs), 기록은 `PlayerRecords.Escaped`, 허브로 돌아가기는 `HubFlow.Return`.

전체 지도는 [스크립트 길잡이](../README.md), 프로젝트 구조는 [구조 안내](../../../../Docs/Architecture.md)에 있다.
