# 전투 규칙과 확장 계획

[프로젝트 안내](../README.md) · [설정·제작 방법](CombatFoundationGuide.md) · [전투 코드 구조](../Scripts/Combat/README.md) · [검증 안내](ValidationGuide.md)

현재 구현된 전투 규칙과 후속 기획을 구분해 정리한다. 아래 수치는 별도 표기가 없으면 **코드 기본값**이며, 실제 플레이에서는 씬·프리팹·설정 asset의 Inspector 값이 우선한다.

## 1. 슬롯과 무기 상태

| 키 | 슬롯 유형 | 빈 슬롯을 선택했을 때 |
| --- | --- | --- |
| 1 / 2 | 원거리 | 주먹 사용 |
| 3 | 근접 | 주먹 사용 |
| 4 | 특수 | 주먹 사용 |

- 주먹은 별도 아이템으로 저장하지 않는다. 선택한 슬롯이 비어 있으면 사용한다.
- 같은 숫자를 다시 누르면 선택을 해제한다. 이때 총·주먹 표시와 좌·우클릭 주먹 전투를 끈다. `Starting Slot = 0`도 해제 상태를 뜻한다.
- `SelectSlot(index)`는 명시적 선택, `SelectSlot(-1)`은 해제, 숫자 입력과 `ToggleSlot`은 선택·해제 토글이다. 런타임 인덱스는 0부터 시작한다.
- 각 슬롯은 독립된 `WeaponRuntime`을 보관한다. 탄창·예비탄은 전환과 컴포넌트 재활성화 뒤에도 유지하며, 전환할 때 진행 중인 장전·차징·가드를 취소한다.
- `TrySetWeapon`은 슬롯 유형을 검사한다. `TryAcquire`는 호환되는 빈 슬롯을 우선 사용하고, 없으면 현재 선택한 호환 슬롯만 교체해 밀려난 데이터를 반환한다.

데이터 교체 API는 구현되어 있다. 실제 필드 아이템·줍기·드롭 연출은 후속 작업이다.

## 2. 원거리 전투

### 조준과 총구 안전성

카메라 중앙의 첫 유효 표면을 조준점으로 삼고, **실제 총구에서 히트스캔을 발사**한다. 총구와 조준점 사이의 벽이 피해를 막는다. 총구 뒤쪽의 조준점, 과도한 근접 수렴, 총구 매몰, 카메라와 총구 사이의 장애물을 감지하면 high-ready 자세로 올리고 발사·탄약 소모·ADS를 차단한다.

총을 올리고 내리는 자세는 부드럽게 전환하지만 엄폐와 발사 차단은 즉시 적용한다. 우클릭을 유지하고 장애물에서 벗어나면 총을 내린 뒤 ADS로 돌아간다. 연사 중에도 격발마다 총구 안전성을 다시 확인한다.

- `WeaponPresentation`은 모델 자세와 가까운 표적↔먼 표적 사이의 수렴을 보간한다. `Aim Follow Half Life`, `Ads Aim Follow Half Life`로 반응을 조절한다.
- `WeaponAimSolver`의 실제 명중·엄폐 판정은 그 시각 보간을 사용하지 않는다. 마우스 회전과 Q/E 입력에도 별도 지연을 넣지 않는다.
- 새 모델의 총구는 로컬 +Z가 전방이어야 한다. 모델이 없는 시험용 컨트롤러는 카메라 위치를 발사 원점으로 사용한다.

### 발사·탄약·장전

| 항목 | 규칙 |
| --- | --- |
| 단발 | 새 클릭마다 한 발. 쿨타임 중 누른 클릭을 뒤늦게 재생하지 않음 |
| 연사 | 누르는 동안 발사 간격을 누적해 처리. 긴 프레임의 몰아 쏘기는 프레임당 최대 4발 |
| 점사 | 클릭당 Burst Count발. 버튼을 놓아도 시작한 점사는 완료하며 점사 사이 Burst Pause 적용 |
| 탄약 | 무기 인스턴스마다 탄창과 유한 예비탄 보관. `WeaponData`에 현재 잔탄을 저장하지 않음 |
| 재장전 | R로 시작. 잔탄이 있으면 Reload Duration, 비었으면 Empty Reload Duration 사용 |
| 탄약 이동 | 장전 완료 순간 한 번만 이동. 예비탄 부족 시 가능한 만큼만 채움. 자동 재장전 없음 |
| 취소 | 회피·무장 밀치기·슬롯 전환·사망·입력 차단 등이 장전과 남은 점사를 정리 |
| 일시정지 | 시간 배율 0에서는 발사·장전 타이머 정지 |

기존 무기에 탄약을 지급할 때는 `WeaponRuntime.AddReserve`를 사용한다. 무기를 새 데이터로 교체하는 것과 예비탄을 보충하는 것은 서로 다른 작업이다.

### 정확도·반동·ADS

- **탄퍼짐**은 도 단위의 원뿔 반각이다. Hip / ADS / Moving / Airborne Spread와 발사 후 Bloom을 합성하며, 크로스헤어도 실제 각도와 FOV를 반영한다.
- **조준 반동**은 실제 조준 방향에 적용된다. Recoil Pattern의 x는 상향, y는 좌우이며 배열을 반복한다. 배열이 없으면 Recoil Per Shot을 사용한다. 응답 속도와 남는 상승량은 Recoil Response / Retention으로 조절한다.
- **화면 킥**은 Gun Feel의 시각 효과다. 실제 조준 반동과 별도이며, 효과 때문에 히트스캔·엄폐 판정이 달라지지 않게 되돌린다.
- **헤드샷**은 총알 피해에 배율을 적용한다. `WeaponHitRegion`의 Head / Body 지정이 우선하고, 현재 단순 적 캡슐은 상단 22%를 머리로 취급한다. 부위 콜라이더는 일반 콜라이더를 사용한다.
- **ADS**는 견착·FOV·지상 이동 배율을 함께 바꾼다. 진입부터 줌 해제가 끝날 때까지 크로스헤어를 숨기고 기존 프로필은 보존한다.
- **Q/E 마이크로 회피**는 ADS와 장전을 유지한다. 일반 스텝 회피는 조준과 장전을 끊는다. 기울이기 중 상체 피격 볼륨은 옆으로 움직이며 이동용 캡슐과 하체는 제자리에 남는다.

## 3. 주먹·밀치기·태클

빈 슬롯을 선택한 상태에서 주먹 전투를 사용한다. 기본 주먹 모델은 절차적 임시 표현이며 정식 모델·애니메이션은 후속 작업이다.

| 행동 | 현재 동작 | 주요 기본값 |
| --- | --- | --- |
| 주먹 | 좌클릭 차징 후 놓을 때 공격. 적중하면 후딜을 해제해 새 클릭으로 연타 가능 | 최대 차징 0.9초, HP 10→28, 체간 10→30, 빗나간 후딜 0.4초 |
| 주먹 판정 | 현재 시점과 프레임 사이 회전·이동 경로를 따라 검사 | 유효 0.18초, 서로 다른 대상 최대 2명 |
| 주먹 V 탭 | 놓을 때 전방의 여러 적을 밀치고 공격 준비 취소 | HP 3, 체간 8, 범위 2.2m / 120도 |
| 총기 V 밀치기 | 같은 다중 대상 밀치기 규칙 사용. 진행 중 장전 취소 | HP 5, 체간 8 |
| 밀침·경직 | NavMesh 이동과 물리 오브젝트에 각각 맞는 밀침 적용 | 초기 속도 8m/s, 감속 0.32초, 경직 0.85초 |
| 주먹 V 홀드 | 적 한 명 확보 → 빠른 접근 → 체간 타격 → 회복 | 홀드 0.14초, 체간 55, 기절 1.4초 |
| 태클 | 주먹 전투가 비활성일 때 전방 달리기 조건을 만족한 V 입력으로 진입 | 별도 몸 충돌 판정, 체간 20, 경직 0.45초 |

공통 근접 검사는 한 공격 ID와 적중 목록을 유지한다. 같은 적의 여러 콜라이더나 왕복 회전으로 피해가 중복되지 않는다. 벽 뒤는 타격하지 않으며, 벽·가드·패링이 주먹 공격을 막으면 그 공격을 종료한다. 밀치기는 앞의 적이 뒤의 적을 가리지 않으므로 범위 내 여러 명을 맞힐 수 있다.

V 홀드는 단일 대상 기술이다. 접근·타격·회복 중에는 이동·시점·공격·방어·회피·슬롯 변경을 잠근다. 벽, 대상 소멸, 접지 상실, 채팅·포커스 상실 등으로 취소되며, 홀드 후 놓을 때 탭 밀치기를 추가하지 않는다.

밀치기 소리는 첫 접촉에 한 번 재생한다. 적 접촉을 벽 소리보다 우선하고, 적중하지 않은 허공에서는 소리가 없다. 슬라이딩 접촉은 `SlideCombat`이 독립적으로 처리한다. **저스트 슬라이드와 몸 크기별 반응·실제 레그돌은 [이동 안내](MovementGuide.md)를 따른다.**

## 4. 가드·패링·완벽 방어

### 가드와 가변 패링

주먹 상태의 우클릭은 전방 **150도**의 방어 가능한 일반 근접 공격을 막는다. 후방·낙하·총알·방어 불가 공격에는 적용하지 않는다.

| 설정 | 코드 기본값 | 의미 |
| --- | --- | --- |
| Parry Window Durations | 0.35 / 0.20 / 0.10 / 0.05초 | 성공 없이 반복 입력할 때 단계별 패링 창 |
| Spam Reset Delay | 0.8초 | 버튼을 놓고 재입력이 없으면 가장 넓은 창으로 복귀 |
| Guard Input Buffer | 0.12초 | 실행할 수 없는 행동 중 새 방어 입력을 잠시 보관 |
| 패링 효과 | 체간 25, 기절 0.8초 | 한 입력에서 한 번 적용 |

- 가드·패링 성공 또는 피격 시 반복 입력 단계를 초기화한다. 단계가 좁아져도 가드 입력 자체를 잠그지 않는다.
- 짧게 눌렀다 놓아도 남은 패링 창은 유지한다. 버튼을 계속 누르면 패링 창이 끝난 뒤 일반 가드로 이어진다.
- 방어는 주먹 차징·공격·밀치기 후딜을 취소한다. 회피·가드 브레이크 등 독점 행동이 끝날 때까지 오래 홀드한 입력은 일반 가드로 복귀하며 새 패링으로 처리하지 않는다.

### 완벽 회피와 반격

실제 공격을 회피 무적 또는 회피 궤적 검사로 피하면 완벽 회피가 성립한다. 패링은 `DamageHit.IsComboFinisher`가 표시된 **연속기의 마지막 타격**일 때 반격 기회를 연다. 단일 공격도 마지막 타격으로 취급한다.

기본 효과는 실제 시간 1초의 반격 창, 0.08배속, 푸른 비네트와 `[LMB] 반격`이다. 새 좌클릭으로 공격자에게 한 번 반격하며 기본 HP 피해 80·체간 피해 60·사거리 4m를 적용한다. 벽이나 다른 몸체에 막힌 대상은 맞히지 않는다.

반격은 기존 공격·장전·회피를 정리하고 같은 입력의 일반 공격을 소비한다. 한 회피에서 여러 공격을 피하더라도 보상·반격 창을 반복 갱신하지 않는다. 사용·만료·피격·사망·처형·입력 상실 시 효과를 해제한다. 일시정지는 반격 시간을 보존한다.

`CombatTimeEffects`가 반격 슬로모션과 히트스톱의 소유권을 관리한다. 개별 공격에서 `Time.timeScale`을 임의로 원상복구하면 다른 효과나 일시정지를 덮어쓸 수 있으므로 이 경로를 사용한다.

### 적 몸 통과

스텝 회피와 마이크로 회피 무적 구간에는 적 몸과 플레이어 사이의 충돌만 임시로 무시한다. 벽·지형·공격 피해 판정은 유지한다. 종료 시 몸 전체가 적 밖의 안전한 위치에 나왔는지 확인한 뒤 충돌을 복구한다. 적과 벽 사이에 갇혀 즉시 복구할 수 없는 쌍은 해소될 때까지 유지하며, 이 보정이 무적 시간을 연장하지는 않는다.

## 5. 체간·흐트러짐·처형

`MeleeCombatTarget`은 체간, 기절, 단일 대상 예약을 관리한다. 체간이 0이 되면 흐트러짐 상태를 유지하고 **체간을 모두 회복해야** 행동 가능 상태로 돌아온다. 기본 회복은 0.35초 대기 후 4초 동안 진행된다. 흐트러진 적에게 체간 피해를 더 주어도 회복 시작과 효과음을 반복 초기화하지 않는다.

처형은 시야 중심과 가까운 거리 안에 있고 벽에 가리지 않은 흐트러진 적 한 명을 대상으로 한다. 기본 선택 범위는 시야 중심 38도·충돌체 거리 2.1m다. 슬롯 선택 여부와 관계없이 F로 실행한다.

- 기본 처형 시간은 0.8초이며 0.35초에 기존 피해·사망 경로로 즉사 타격한다. 사망 이벤트와 웨이브 집계는 유지한다.
- 처형 전체 구간에 HP·실드를 보호하고 이동·시점·공격·장전·방어·회피·슬롯 전환을 잠근다. 회피 보상은 만들지 않는다.
- 대상의 체간 회복을 예약 중 멈춘다. 타격 전 대상 소멸·비활성화, 플레이어 초기화·비활성화, 채팅·포커스 상실 시 취소하고 잠금을 해제한다.
- 같은 씬의 적은 공격 준비를 취소하고 추적·공격을 멈춘다. 가까운 정상 NavMesh 적은 벽과 이동 영역 안에서 물러나며, 기절·흐트러짐 중인 적은 움직이지 않는다.
- 정식 처형 애니메이션은 아직 없다. `PlayerExecution.Started / Impact / Ended` 이벤트에 모델 연출을 연결한다.

HP·체간 바, 흐트러짐 표시와 처형 안내는 기존 적·프리팹에도 실행 시 연결된다. 새 적 AI를 추가할 때는 `MeleeCombatTarget.IsStunned`, 넘어짐, `PlayerExecution.Suppresses`를 존중해야 한다.

## 6. 타격감과 화면 표시

전역 설정은 [GunFeel.asset](../Resources/Combat/GunFeel.asset), 무기별 화면 킥·총성·총알 반응은 `WeaponData`의 Feel 항목이다. 방어·반격·피해 팝업·HP 손실 표시는 [Feedback.asset](../Resources/Combat/Feedback.asset)에서 조절한다. 빈 사운드 슬롯은 해당 Gun Feel 합성음을 사용한다.

| 층 | 구성 | 조절할 때의 경계 |
| --- | --- | --- |
| 발사 | `WeaponFeedback`, 화면 킥, 총구 섬광·연기·조명, 탄피, 총성·장전음 | 화면 킥과 실제 조준 반동을 구분 |
| 명중 | `GunFeelDirector`, 히트마커·확인음·혈흔·피해 팝업 | 받아들여진 피해 보고에서 표시 생성 |
| 처치 | 점수·킬로그·선택적 화면 펄스·시각 사본 쓰러짐 | 사망과 웨이브 집계는 원래 피해 수신자가 처리 |
| 적 반응 | `EnemyHitReaction`의 밀림·감속·공격 취소·기절 | 실제 게임 규칙이므로 화면 효과와 별도로 조절 |

### 히트마커와 점수

| 판정 | 히트마커 |
| --- | --- |
| 몸샷 | 흰 X |
| 헤드샷 | 몸샷과 같은 크기의 금색 X |
| 몸샷·헤드샷 처치 | 같은 빨간 X와 충격 링 |
| 가드·패링·무적 등 피해 없음 | 얇은 회색 X |

히트마커는 기준 60fps에서 7프레임 넓게 유지 → 9프레임 동안 선을 안쪽으로 이동 → 1프레임 흐리게 표시한 뒤 사라진다. 실제 프레임률과 무관하게 같은 시간을 사용한다. 새 적중은 다시 넓은 상태로 시작하되, 막 뜬 처치 마커는 0.18초 동안 후속 일반 명중이 덮어쓰지 않는다.

점수는 처치에만 부여한다. 크로스헤어 오른쪽 아래에 점수와 처치 사유를 표시하고 연속 처치 동안 누적한다. 헤드샷·처형·반격의 사유는 금색으로 표시하므로 헤드샷 처치는 마커의 추가 왕관 대신 이 줄로 구분된다. 오른쪽 위에는 누적 XP와 킬로그가 나온다. `Score Font`, `Score Offset`, 보너스와 유지 시간을 GunFeel에서 조절한다.

히트마커와 피해 팝업은 화면 킥이 적용된 카메라를 기준으로 그려진다. 실제 조준점과 명중 대상의 연결을 유지하면서 화면 효과를 따라간다. 확인음은 기존 타격음 위에 추가되며 헤드샷용 별도 종소리는 사용하지 않는다.

### 적 피격과 처치 효과

총알은 기본적으로 적을 밀고 잠시 감속시킨다. 헤드샷 또는 짧은 시간에 누적된 몸샷 피해가 조건을 만족하면 공격 준비를 취소하고 기절시킨다. 연속 기절에는 쿨다운이 있다. 총알의 체간 피해는 무기별 Posture Damage와 GunFeel의 헤드샷 배율을 사용한다. 체간 피해 자체가 매번 공격을 취소하지는 않으며, 체간 0에서는 흐트러짐이 된다.

피격 발광은 잠시 오버레이 재질을 추가한 뒤 제거한다. 처치 시 `CorpseTopple`은 제거되는 적의 시각 사본을 넘어뜨리고 가라앉힌다. 이 사본에는 충돌체가 없으며, 슬라이딩에 의해 살아 있는 적이 실제 물리로 넘어지는 `EnemyKnockdownPresentation`과 구분한다.

화면 전체 처치 펄스는 기본적으로 **처형·완벽 방어 반격 처치**에만 적용한다. 일반 총기 처치는 `Kill Pulse On Gun Kill`을 켰을 때 적용한다. 펄스 동안의 포스트 프로세싱은 종료 후 기존 카메라 상태로 복구한다. 각 층은 GunFeel의 Master Switches에서 개별로 끌 수 있다.

## 7. 확정된 후속 방향

아래는 이후 구현할 기획이다. 현재 게임에 연결되어 있는 기능으로 취급하지 않는다.

1. 필드 무기는 호환되는 빈 슬롯에 자동으로 들어가거나, 현재 선택한 호환 무기와 교체한다. 기존 `TryAcquire`에 필드 아이템·상호작용·드롭을 연결한다.
2. 빈 슬롯에서 궁극기를 사용하면 잠깐 시간을 멈추고, 슬롯 유형에 맞는 하위 티어 무기 3개 중 하나를 선택한다.
3. 무기를 든 슬롯에서 궁극기를 사용하면 해당 무기를 한 단계 진화시킨다.
4. 최종 진화 상태에서는 해당 무기의 고유 궁극기·스킬·버프를 사용한다.
5. 1티어 무기의 Q/E는 기존 기울이기·마이크로 회피를 유지한다. 진화 후에는 무기별 액티브로 바뀔 수 있다. 카타나 Q 찌르기·E 대시는 예시다.
6. 기본 가드 브레이크는 한 명을 대상으로 하며, 후속 스킬로 여러 적에게 기절이 퍼지도록 확장할 수 있다.

무작위 3지선다 UI, 시간 정지 선택 흐름, 티어·진화 경로, 고유 궁극기, 진화 Q/E, 다중 대상 가드 브레이크는 아직 구현되지 않았다. 기존 궁극기 게이지·초상화·불꽃 표시는 후속 시스템을 연결할 기반으로 유지한다.
