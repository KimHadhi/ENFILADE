# 무기 슬롯·획득·진화 기획

사용자가 2026-10-21에 정한 방향과 2026-10-22 플레이 피드백을 반영했다. 이후 무기 시스템을 확장할 때 이 문서를 기준으로 한다.

## 슬롯 규칙 — 현재 구현

| 키 | 슬롯 유형 |
| --- | --- |
| 1 | 원거리 |
| 2 | 원거리 |
| 3 | 근접 |
| 4 | 특수 |

- 빈 슬롯도 선택 상태를 유지하며 기본 주먹을 사용한다. 주먹은 슬롯에 저장된 무기 아이템이 아니다.
- 같은 숫자를 다시 누르면 슬롯을 해제한다(`SelectedSlot = -1`). 이 상태에서는 총과 주먹 모델을 모두 내리고 LMB/RMB 주먹 전투도 비활성화한다. 빈 슬롯을 선택한 상태와는 다르다. `startingSlot = 0`은 슬롯을 선택하지 않고 시작한다는 뜻이다.
- 숫자 입력과 `ToggleSlot`은 선택/해제를 토글한다. 코드의 `SelectSlot`은 명시한 슬롯을 선택하고, `SelectSlot(-1)`은 모두 해제한다.
- 각 무기의 탄약은 슬롯별로 독립적이며 전환해도 보존한다. 전환하면 진행 중인 장전·차징·가드를 취소한다.
- `WeaponData.Category`와 `PlayerWeaponSlots.IsCompatible/TrySetWeapon`으로 슬롯 유형을 검사한다. 기존 총기 데이터의 기본 유형은 Ranged다.
- `TryAcquire`는 호환되는 빈 슬롯을 먼저 찾는다. 빈 슬롯이 없으면 현재 선택된 호환 슬롯만 교체하며, 밀려난 데이터를 호출자에게 돌려준다. 원거리 슬롯이 가득 찬 상태에서 3번을 선택하고 원거리 무기를 주워 교체하는 것은 불가능하다.
- 실제 필드 아이템, 드롭·상호작용 연출, 새 무기 데이터는 이번 구현 범위에 포함하지 않는다.

## 원거리 전투 — 현재 구현

- LMB는 카메라 중앙의 첫 유효 표면을 조준점으로 삼고 **실제 총구에서** 즉시 히트스캔을 발사한다. 총구와 조준점 사이의 벽은 피해를 막는다. 총구 뒤에 조준점이 있거나, 과도한 근접 수렴·총구 매몰·카메라와 총구 사이의 장애물이 있으면 high-ready로 올리고 발사/탄약 소모를 막는다. 벽에서 벗어난 뒤 자세가 내려오면 사격을 재개한다. 총구 위치가 반동으로 움직인 연속 사격도 격발마다 안전성을 다시 확인한다.
- 하이레디는 마지막으로 표시한 무기의 위치·회전에서 목표 자세까지 카메라 기준으로 보간한다. 올릴 때와 내릴 때 모두 최종 자세에 한 번만 적용하므로 조준 보정이 복귀 동작을 지우지 않고, ADS가 즉시 해제돼도 무기가 순간 이동하지 않는다. 벽 앞 사격·줌 차단은 즉시 적용한다. 무기 데이터의 `High Ready Raise Half Life`(기본 0.045초), `High Ready Lower Half Life`(0.055초)로 조절하며 값이 클수록 부드럽고 느리게 전환한다. 마우스 회전·Q/E는 현재 카메라에 바로 따라간다.
- 총 모델은 조준점을 계속 따라간다. `WeaponController`의 `Weapon Root`/`Muzzle Point`가 비어 있으면 기존 `WeaponVisibility.GunRoot`와 `BulletTracerEffect.MuzzlePoint`를 찾는다. 모델이 없는 테스트용 컨트롤러는 카메라 위치를 사용한다. 새 모델에서는 실제 총구의 +Z가 발사 방향이 되도록 지정한다. 탄흔·피·총구 화염·`ShotFired` 이벤트는 유지하고 트레이서 시작점은 실제 발사 원점과 일치시킨다.
- 단발은 새 클릭마다, 연사는 누르는 동안, 점사는 클릭당 `Burst Count`발 발사한다. 기존 enum 0=단발/1=연사는 유지하고 2=점사를 추가했다. 점사 중 버튼을 놓아도 해당 점사는 완료되지만 장전·회피·밀치기·무기 교체·장애물·입력 차단 시 남은 점사는 취소한다. 점사 사이 `Burst Pause`를 적용한다.
- `WeaponData`의 탄퍼짐은 **각도(원뿔 반각, 도)** 기준이다. `Hip Spread`, `ADS Spread`, `Moving Spread`, `Airborne Spread`, `Bloom Per Shot / Max Bloom / Bloom Recovery`로 조절한다. 사격할수록 벌어지고 쉬면 회복한다. 크로스헤어도 실제 FOV와 이 각도에 맞춰 확장한다. `Recoil Pattern`의 x=상향 반동, y=좌우 반동이며 배열을 반복한다. 배열이 비어 있으면 `Recoil Per Shot`을 사용한다. 0.35초 쉬면 패턴을 처음부터 시작하며 ADS 반동은 65%다. 반동은 각도를 즉시 더하지 않고 정확해를 사용하는 감쇠 스프링으로 약 40ms 동안 상승한 뒤 복귀한다. `Recoil Feel → Recoil Response`는 응답 속도, `Recoil Retention`은 복귀하지 않고 부드럽게 누적되는 조준 상승 비율이다(라이플 22%, 피스톨 20%). 마우스 입력 자체에는 보간을 적용하지 않는다. `Weapon Kick Back / Weapon Kick Up / Weapon Recoil Response`로 총 모델의 뒤로 밀림·들림·복귀 속도를 조절한다. ADS에서는 총 모델 들림을 제거하고 뒤로 밀림만 줄여 적용하여 가늠쇠와 실제 조준선을 유지한다. 무기 교체 시 대기 중 반동을 지우되 현재 보이는 시점은 유지한다. 프레임률 변화·긴 프레임·슬로모션에도 스프링이 발산하지 않는다.
- 헤드샷은 `Headshot Multiplier`(현재 2배)를 적용한다. 현재 적 캡슐은 상단 22%를 머리로 취급한다. 모델별 콜라이더에 `WeaponHitRegion`을 붙여 Head/Body를 명시하면 그 설정이 우선한다. 해당 부위 콜라이더는 일반(non-trigger) 콜라이더로 설정한다. 이 배율은 총알에만 적용하고 기존 근접 공격은 유지한다.
- RMB 유지 시 `ADS Transition Time`에 따라 견착, `ADS FOV`로 줌, `ADS Move Multiplier`로 지상 이동 속도 감소를 적용한다. 기존 Q/E 기울이기와 병행 가능하다. `Sight Height`는 총구 축에서 가늠쇠까지 높이로 모델별 조절한다. 카메라 FOV는 기존 `PlayerCameraEffects` 한 곳에서 이동 효과와 합성한다. ADS 전환 시간에 맞춰 줌을 적용하고 중복 보간으로 늦어지지 않게 한다. 정조준 진입부터 줌 해제가 끝날 때까지 크로스헤어의 점과 선을 숨긴다. 저장된 크로스헤어 프로필은 바꾸지 않으며 조준 해제·회피·슬롯 전환 시 복구한다. 기울이는 동안 상체 피격 볼륨은 옆으로 이동하며 하체와 이동용 캡슐은 제자리에 남는다. 상호작용용 일반 트리거는 총알을 막지 않는다.
- 탄창/예비 탄약은 각각 무기 인스턴스에 저장하고 슬롯 전환·컴포넌트 재활성화에도 보존한다. `Initial Reserve Ammo`는 최초 보유량이며 향후 탄약 획득은 `WeaponRuntime.AddReserve`로 연결한다. R은 잔탄이 있으면 기존 `Reload Duration`, 비어 있으면 `Empty Reload Duration`을 사용한다. 탄약 이동은 완료 순간 한 번만 일어나므로 취소 시 손실·복제가 없다. 예비 탄약이 부족하면 가능한 만큼만 장전하며 0이면 장전을 시작하지 않는다. 자동 재장전은 없다.
- 회피 시작과 무장 상태 V 밀치기는 장전을 즉시 취소한다. 같은 프레임의 R보다 생존 행동이 우선한다. 밀치기가 적중하면 즉시 후속 사격이 가능하고 빗나가면 `WeaponController → Missed Shove Recovery`(기본 0.25초)를 적용한다. 태클·파쿠르·구르기 중 사격은 막되, 일반 회피·슬라이딩 중 지향 사격은 유지한다. 기존 슬로모션은 사격과 장전 시간에도 그대로 적용한다.
- 기본 라이플: 예비 90발, 전술 1.5초/빈 탄창 2초, ADS 40도/이동 60%. 기본 피스톨: 예비 48발, 전술 1.2초/빈 탄창 1.65초, ADS 45도/이동 70%. 두 데이터는 `Assets/_Project/Data/Combat/Weapons`에서 조절한다. 현재 기존 총 모델을 사용하며 손/탄창 교체의 정식 애니메이션은 이후 모델 작업에 연결한다.
- 검증: `RangedCombatChecks`는 탄약 보존·점사 30/60/120Hz·총구 수렴과 엄폐·high-ready·부위 피해·ADS와 탄퍼짐·생존 취소·기울이기 피격 볼륨을 검사한다. `RangedCombatPlayChecks`는 실제 CombatFoundation 씬의 총 모델 연결, 줌, 반동, 회피/밀치기 취소, 슬롯 탄약 유지, 벽 앞 자세와 native 캐릭터 충돌체 복구를 검사한다.

## 주먹 근접 전투 — 현재 구현

- LMB: 누르면 차징, 놓으면 공격 시작. 기본 최대 차징 0.9초, HP 피해 10→28, 체간 피해 10→30. 적중하면 후딜을 즉시 해제하여 다음 클릭으로 바로 연타할 수 있다. 빗나간 경우에만 기존 0.4초 회복 시간을 유지한다. 좌우 주먹을 번갈아 내며 접지 상태에서 짧은 전진 보정(0.12m)을 적용한다.
- 주먹은 발동 후 0.18초, 밀치기는 0.2초 동안 현재 시점에 따라 타격 판정이 움직인다. 프레임 사이의 회전·이동 경로도 세분해 검사하므로 빠르게 화면을 돌렸을 때 중간의 적을 건너뛰지 않는다. 유효 시간이 끝난 뒤에는 판정이 남지 않으며, 다음 공격·가드·슬롯 교체·행동 취소 때 이전 공격의 판정을 제거한다.
- 한 공격 ID와 적중 목록을 유효 시간 전체에 공유하여 같은 적의 여러 충돌체나 왕복 회전으로 중복 피해·체간 피해·밀침이 발생하지 않는다. 주먹은 기본 최대 2명의 서로 다른 대상을 타격한다(`PlayerMeleeCombat → Attack Max Targets`). `Attack Active Time`은 주먹의 판정 지속 시간, `Ability Settings → Crowd Shove → Shove Active Time`은 밀치기의 판정 지속 시간이다.
- 공통 `MeleeAttackSweep`은 사거리·판정 두께·유효 시간·최대 타격 대상 수를 공격별로 받는다. 이후 레이피어 등의 관통력은 이 대상 수로 연결할 수 있다. 벽이나 가드·패링에 막히면 해당 근접 공격은 종료한다. 새 무기나 모델을 추가한 것은 아니다.
- RMB: 전방 120도 일반 근접 공격을 가드. 누른 뒤 0.18초 이내 첫 공격은 패링으로 체간 25 피해와 0.8초 기절을 준다. 같은 입력으로 패링 보상을 반복하지 않는다. 후방·낙하·방어 불가 공격과 총알은 방어하지 않는다.
- V Tap: 놓을 때 전방 120도·2.2m 범위를 밀친다. 범위 내 여러 적에게 각각 한 번씩 피해 3, 체간 8을 주고 공격 준비를 취소하며 0.85초 동안 경직시킨다. 앞의 적이 뒤의 적을 가리지 않으며 벽 뒤·후방·범위 밖 대상은 맞지 않는다. 한 적의 여러 충돌체에 중복 적중하지 않는다. NavMesh 적은 초기 속도 8m/s에서 0.32초 동안 감속하며 약 1.28m 밀린 뒤 남은 시간 동안 비틀거리며 행동할 수 없다. 벽과 이동 영역 경계에서 밀림을 제한한다. 물리 오브젝트는 충격량을 받는다.
- V Hold: 0.14초 이상 누르면 시야 앞 근거리의 적 한 명을 확보한다. 접근 속도는 12m/s이며, 실제 타격 거리 안에 들어오면 최소 0.04초 후 바로 체간 55 피해와 1.4초 기절을 준다. 접근 제한 시간은 0.24초, 타격 후 플레이어 회복 시간은 0.16초다. 가까운 적에게도 고정된 접근 시간을 기다리던 방식을 제거했다. 시전 중 이동·시점·공격·가드·회피·슬롯 교체를 잠근다. 벽, 대상 소멸, 범위 이탈, 접지 상실, 채팅·포커스 상실 시 취소한다. 길게 누른 뒤 놓을 때 밀치기를 추가로 발동하지 않는다.
- 총을 든 밀치기도 동일한 다중 대상 판정·밀림·0.85초 경직을 사용한다. 기본 HP 피해는 5, 체간 피해는 8이다. 달리면서 사용하는 태클은 기존 별도 판정을 유지하며 체간 20과 0.45초 경직을 적용한다.
- 밀치기 범위·각도·힘·경직은 플레이어의 `Ability Settings → Crowd Shove`에서 조절한다. `Shove Sweep Reach` 2.2, `Shove Sweep Angle` 120, `Shove Push Speed` 8, `Shove Stun` 0.85가 기본값이다. V 홀드 가드 브레이크는 계속 한 명을 붙잡는 기술이다.
- 주먹/총 밀치기가 적에게 적중하면 사용자 제공 `rifle_swing_hit_infected7~12.wav` 중 하나를 무작위 재생하며 바로 직전 소리는 피한다. 적을 맞히지 않고 벽·일반 물체에 닿으면 `rifle_swing_hit_world.wav`, 허공이면 타격음이 없다. 첫 접촉 시 한 번만 재생하며 같은 검사에서 적과 벽이 함께 맞으면 적 타격음을 우선한다. 이후 화면 회전으로 추가 적을 맞혀도 소리를 겹쳐 재생하지 않는다. `Assets/_Project/Resources/Combat/Feedback`의 `Shove Enemy Volume`, `Shove World Volume`에서 음량을 각각 조절하며 기본값은 모두 0.3이다.
- Q/E: 기존 기울이기와 마이크로 닷지를 유지한다. 가드 브레이크 시전 중에는 차단한다.

- 같은 씬의 적은 공격 준비를 취소하고 추적/공격을 멈춘다. 가까운 정상 상태의 NavMesh 적은 플레이어를 바라보며 초당 2.8m 속도로 2.6m 밖까지 후퇴한다. 벽과 NavMesh 경계를 통과하지 않으며 흐트러짐·기절 중인 적은 후퇴도 하지 않는다. 종료 후 추적이 재개되고 새 공격 준비가 필요하다.
- 대상 체간 회복은 처형 예약 중 멈춘다. 타격 전 대상 소멸·비활성화, 플레이어 리셋·비활성화, 채팅·포커스 상실 시 취소하고 잠금을 해제한다. 일시정지는 처형 시간을 보존한다.
- 표시/사운드/폰트 참조는 `Assets/_Project/Resources/Combat/Feedback.asset`, 검사는 `WeaponSlotsMeleeChecks`에 있다. 새로운 적 AI도 `MeleeCombatTarget.IsStunned`와 `PlayerExecution.Suppresses`를 존중해야 한다.

## 타격감(Gun Feel) — 현재 구현

`Scripts/Combat/Feel`에 세 층으로 구현했고 모두 실행 시 자동 연결되어 씬·프리팹 수정이 필요 없다. 전역 수치는 `Resources/Combat/GunFeel`, 무기별 손맛·소리는 `WeaponData`의 **Feel** 항목에서 조절한다. 사운드 슬롯을 비워 두면 내장 합성음을, 클립을 넣으면 그 클립을 쓴다. 무기·캐릭터 모션은 이후 연결한다.

### 1. 쏜다는 느낌 — `WeaponFeedback`(WeaponController가 자동 추가)

- **비주얼 리코일**(`CameraViewPunch`): 발사마다 화면을 위로 차올리고 좌우·롤을 흔들며 FOV를 순간 넓힌다. 연사하면 셰이크가 누적된다. 화면에만 적용하고 다음 프레임 전에 되돌리므로 조준·히트스캔·엄폐 판정은 흔들리지 않는다(탄은 항상 크로스헤어로 간다). 총 모델은 카메라와 함께 튄다. ADS에서는 55%. 무기별 `View Punch`(x 위, y 좌우, z 롤), `View Punch Fov`, `Shake Trauma`.
- **반동**: 기존 조준 반동과 총 모델 킥을 유지하고, 크로스헤어가 격발마다 잠깐 벌어진다.
- **VFX**: 별 모양 총구 섬광과 측면 화염, 주변을 밝히는 총구 조명, 연기, 불꽃, 바닥에서 튕기는 탄피(소리 없음).
- **SFX**: 무기별 `Sound Profile`(Rifle/Pistol/Heavy) 합성 총성(4종 변주·피치 흔들림), 잔탄 30% 이하의 점점 높아지는 건조한 틱, 마지막 탄의 빈 클릭, 빈 탄창 격발음, 장전 시 탄창 분리→삽입(빈 탄창이면 노리쇠까지).

### 2. 맞췄다는 느낌 — `GunFeelDirector`가 `CombatDamageEvents`를 받아 분배

- **히트마커**(`HitMarkerHUD`): 몸샷=흰 X, 헤드샷=금색 큰 X, 처치=빨간 X+충격 링, 헤드샷 처치=빨간 X+금색 왕관·링, 피해 없음(가드·패링·무적)=얇은 회색 X. 크게 나타나 작아지며 사라지고, 연속 명중하면 커진다. 흔들리지 않은 조준점을 킥이 적용된 화면에 투영해 그리므로 화면 킥을 따라 튀었다가 돌아온다. 데미지 팝업도 같은 순서(실행 순서 10010)로 그려 킥 중에도 적에게 붙어 있다.
- **확인음**: 기존 살 타격음(`CombatHitAudio`) 위에 명중 시 부드러운 틱, 처치 시 낮은 '쿵+휙'. 헤드샷은 관통 타격음과 금색 마커로 구분하며 별도 '딩'은 없다.
- **혈흔**(`ImpactVfx`): 출구 쪽으로 더 많이 튀는 핏방울과 피 안개, 뒤쪽 벽·바닥의 혈흔(9초 후 사라짐). 헤드샷·처치는 더 세게 튄다.
- **데미지 팝업**: 기존 `DamagePopupManager`.
- **점수**(`CombatFeedHUD`, MW3식): 처치에만 점수를 준다. 크로스헤어 오른쪽 아래(`Score Offset`)에 `100 XP`가 떨어지듯 나타나고, 옆에 `☠ 처치`, `헤드샷`, `원거리 사격`(총 25m 이상), `처형`, `반격`, `더블/트리플/쿼드 킬·연속 처치 xN`이 차례로 들어온다. 연속 처치 동안 숫자가 누적되고 2.4초 조용하면 사라진다. 오른쪽 위에는 `XP` 누적값과 킬로그(`[무기] [아이콘] [대상]`, 5초). 글꼴은 `Score Font`(기본 Pretendard ExtraBold).
- **킬 이펙트(GTA풍)**(`KillConfirmEffect`): 처형과 완벽 방어 반격 처치에만 적용한다(`Kill Pulse On Execution/Counter/Gun Kill/Other Kill`). 0.5초 동안 채도↓·노출↑·비네트·색수차·약한 렌즈 수축, 짧은 히트스톱과 카메라 쿵. 평소 화면은 건드리지 않는다: 기본 볼륨 프로필의 ACES 톤매핑 등이 적용되지 않도록, Post Processing이 꺼진 카메라에서는 펄스 동안만 켜고 기본 프로필을 상쇄하는 중립 볼륨을 함께 켠 뒤 원래대로 끈다.

### 3. 맞았다는 느낌

- **경직·넉백·공격 불능**(`EnemyHitReaction`, 게임플레이): 총알마다 사격 방향으로 밀고(몸 0.12m/머리 0.2m) 0.4초간 이동속도를 30%로 낮춘다. 헤드샷은 공격 준비를 취소하고 0.35초 기절, 0.7초 안에 최대 체력 30% 이상의 몸샷 피해가 쌓여도 취소·0.3초 기절. 기절 뒤 1초 쿨다운으로 영구 경직은 막는다. 총알은 체간도 깎는다(`Posture Damage`, 라이플 4/피스톨 9, 헤드샷 1.5배). 체간 피해만으로 공격을 끊지는 않지만 0이 되면 흐트러짐·처형이 가능하다. 무기별 `Flinch Multiplier`(피스톨 1.35).
- **피격 발광**(`HitFlashRenderer`): 전신이 빨갛게 번쩍이고 붉은 림이 생기며 실제 탄착점이 발광했다가 식는다(최대 4곳). 맞는 동안만 오버레이 머티리얼을 덧붙여 원래 머티리얼은 바뀌지 않는다.
- **체력 바**: 기존 `EnemyVitalsHUD`(손실 꼬리·흔들림·흰 플래시).
- **처치 쓰러짐**(`CorpseTopple`): 적은 기존처럼 즉시 제거되고(웨이브 집계·`Died` 유지), 충돌체 없는 시각 사본이 하얗게 달아올랐다 식으며 사격 방향으로 넘어져 바닥에 부딪힌 뒤 가라앉는다. 정식 사망 모션을 연결하면 `Death Topple`을 끈다.

### 조절과 검증

- 각 기능은 `GunFeel`의 Master switches로 개별로 끌 수 있다.
- 검증: 격리 프로젝트에서 `-batchmode -executeMethod GunFeelPlayChecks.RunBatch`(`-quit` 없이). 실제 CombatFoundation 소총으로 몸샷·헤드샷·처치·헤드샷 처치와 처형 처치를 하며 위 각 층과 카메라 Post Processing 유지를 확인한다.

## 획득과 궁극기 — 이후 구현할 확정 방향

1. 필드 무기는 유형에 맞는 빈 슬롯에 자동으로 들어가거나, 호환되는 현재 무기와 교체한다.
2. 빈 슬롯(주먹)을 선택한 상태에서 궁극기를 사용하면 잠깐 게임 시간을 멈춘다.
3. 해당 슬롯 유형에 맞는 무작위 하위 티어 무기 3개를 제시하고, 플레이어가 하나를 선택해 슬롯에 넣는다.
4. 무기를 든 상태에서 궁극기를 사용하면 해당 무기를 상위 티어로 한 단계 진화시킨다.
5. 최종 진화 상태에서는 더 진화하지 않고 그 무기의 고유 궁극기(특수 스킬·버프 등)를 사용한다.
6. 1티어 무기는 고유 Q/E 액티브가 없어 기존 기울이기·마이크로 닷지를 사용한다. 진화하면 Q/E가 무기별 스킬로 바뀔 수 있다. 카타나의 Q 찌르기, E 대시는 예시다.
7. 가드 브레이크는 기본 한 명에게만 적용한다. 이후 스킬로 주변 여러 적에게 기절이 확산되도록 확장할 수 있다.

랜덤 3지선다, 시간 정지 선택 UI, 티어/진화 경로, 고유 궁극기, 진화한 Q/E 스킬, 다중 대상 가드 브레이크는 현재 동작으로 구현하지 않는다. 기존 궁극기 게이지는 유지하며 이 기획을 연결할 후속 작업으로 둔다.

## 검증

`Tools → Combat → Run Four Slots and Fists Checks`는 별도의 임시 씬에서 슬롯 유형, 빈 슬롯 선택, 탄약 보존, 차징/놓기, 벽 차단, 가드/패링, V 탭/홀드, 단일 대상, 취소와 행동 잠금 해제를 검사한다.
기존 총기 검사는 `Run Foundation Checks`, 이동 검사는 `Tools → Movement → Run Refactor Checks`를 사용한다.

흐트러짐 회복·처형 예약과 취소·무적·HUD·적 공격 중단은 위 검사에 포함된다. 실제 NavMesh 후퇴는 편집 모드에서 에이전트가 활성화되지 않으므로 별도 격리 프로젝트에서 `-batchmode -executeMethod ExecutionCrowdPlayChecks.RunBatch`로 검사한다(`-quit` 없이 실행하며 완료 시 스스로 종료). 이 검사는 가까운 적의 후퇴, 벽 차단, 거리 확보 후 정지, 흐트러진 적의 이동 금지, 종료 후 이동 복구를 확인한다.
