# 이동·회피·파쿠르 안내

[프로젝트 안내](../../../README.md) · [전투 안내](CombatFoundationGuide.md) · [플레이어 몸](PlayerBodyGuide.md) · [이동 코드 구조](../Scripts/Player/Movement/README.md)

현재 조작은 [Player.inputactions](../Input/Player.inputactions)를 기준으로 합니다. 아래 수치는 [Player.csv](../Resources/Tables/Player.csv)의 기본값이며, 표를 고치면 바로 바뀝니다. 기능을 시험할 때는 [CombatFoundation](../Scenes/Development/CombatFoundation.unity) 또는 [MovementAbilityPlayground](../Scenes/Development/MovementAbilityPlayground.unity)를 사용합니다.

## 기본 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 조작 |
| 전진 / Shift + 전진 | W만 눌러도 속도가 쌓여 달리기가 된다. Shift는 곧바로 질주 속도로 올린다 |
| Space | 점프. 이동 중 앞에 넘을 수 있는 장애물이 있으면 Vault 우선 |
| Ctrl 유지 | 앉기. 공중에서는 몸을 접어 캡슐 높이 축소. Esc 설정에서 "눌러서 전환"으로 바꿀 수 있다(Q/E 기울이기도 같음) |
| 서서 이동 중 Z | 입력 방향으로 다이브. 뒤 입력은 누운 다이브 |
| 제자리 Z / 앉은 상태에서 Z | 포복 |
| 포복·누운 상태에서 Space | 공간이 있으면 먼저 일어나기 |
| 포복·누운 상태에서 Ctrl 또는 Z 재입력 | 가능한 앉기·서기 자세로 전환 |
| 포복·누운 상태에서 Shift + 이동 | 서 있을 공간이 있으면 빠르게 기상 |
| 달리는 중 Ctrl 새로 누르기 | 실제 속도가 충분하면 슬라이딩 |
| 슬라이딩 중 Alt | 가속과 저스트 슬라이드 판정 시작 |
| 지상에서 Alt + 방향 | 스텝 회피. 방향 입력이 없으면 뒤로 회피 |
| 지상에서 Q / E | 좌우 기울이기와 짧은 마이크로 회피 |
| 달리는 중 V | 돌진 밀치기. 처음 만난 적을 날려 넘어뜨린다 |
| 세게 착지하기 전 0.5초 안에 Ctrl | 구르기. 피해와 감속 없이 속도를 이어 간다. 5m/s보다 느리거나 S를 누르고 있으면 피해 없이 제자리에 착지한다 |

Alt는 좌우 Alt 모두 연결되어 있습니다. F 상호작용과 V 전투 동작은 [전투 안내](CombatFoundationGuide.md)에서 다룹니다.

달리기는 3.8m/s에서 출발해 속도가 쌓입니다. W만 누르면 1초에 5.2m/s, 3.5초에 8.4m/s가 되고, Shift는 곧바로 8.4m/s가 됩니다. 최고는 9.5m/s입니다(자세한 규칙은 [속도 쌓기](#속도-쌓기)). 앉기는 3m/s, 포복·누운 이동은 1.6m/s입니다. 점프 높이는 1.3m이며, 발판을 벗어난 직후 0.1초와 착지 직전 입력 0.15초를 보정합니다.

낮은 고정 천장 앞에서 앉아 이동하면, 포복 캡슐과 진입 경로가 비어 있을 때 자동으로 엎드립니다. 몸 전체가 통로를 빠져나오기 전에는 일어서지 않습니다. 정지한 누운 자세에서는 A/D와 S로 이동하고, W로 기상을 시도합니다. 누운 슬라이딩 중 W는 기상 입력으로 사용하지 않습니다. 대신 누운 슬라이딩이 0.5초(`Move.slideCancelMinDuration`) 이어지고 5m/s(`Move.supineSlideCancelMaxSpeed`) 아래로 느려지면 **Shift + 이동 키**나 **Space**로 미끄러지는 도중에 바로 일어납니다(Ctrl을 누르고 있거나 천장이 낮으면 앉기로). Shift + 이동 키를 누른 채 멈추면 눕지 않고 그 자리에서 일어납니다. 그냥 두면 전처럼 멈춘 뒤 누운 자세가 됩니다.

## 슬라이딩과 저스트 슬라이드

### 진입·조향·종료

전진을 유지한 채 달리다가 Ctrl을 새로 누릅니다. 실제 이동 속도가 기본 5.3m/s(`Move.slideMinStartSpeed`) 이상이면 시작하므로 Shift는 없어도 되고, 벽에 막힌 채 달리기 키만 누르면 시작하지 않습니다.

A/D로 제한적으로 조향할 수 있습니다. 시선은 미끄러지는 방향에서 좌우 `Body.slideTurnLimit`까지 돌고, 마우스를 그 끝 너머로 계속 밀면 미끄러지는 방향이 시선을 따라 돕니다(땅에 붙어 있을 때만, 최대 `Move.slideLookSteerRate` 90도/초. 0이면 시선이 끝에서 멈춥니다). 몸이 어느 쪽을 보고 미끄러지는지(앞을 보고, 또는 뒤로 달리다 슬라이딩하거나 벽에 튕겨 뒤로)는 슬라이드가 시작될 때와 튕길 때 정해져 끝까지 그대로라, 시선을 90° 넘게 돌려도 다리와 몸이 돌지 않습니다. 누운 슬라이딩도 몸이 누운 방향을 지키고, 시선은 누워 있을 때처럼 그 방향에서 좌우 110°(`Body.lyingLookLimit`)까지 돕니다. 반대 방향을 입력하거나 Ctrl을 놓았다가 다시 누르면 제동합니다. 내리막은 가속하고 오르막은 감속하며, 기본 최대 슬라이딩 경사는 65도입니다. 감속 후에는 입력과 머리 공간에 맞춰 서기·앉기·포복으로 전환합니다.

일반 슬라이딩은 시작 0.1초 후 Space로 다이브 도약을 할 수 있습니다. 머리부터 미끄러지는 자세와 누운 슬라이딩에서는 이 점프를 사용하지 않습니다(누운 슬라이딩의 Space는 위의 바로 일어나기입니다).

### 적과 접촉했을 때

슬라이딩 중 Alt를 새로 누르면 속력이 기본 **1.5m/s 증가**하고, 가속 시작부터 **0.18초** 동안 저스트 슬라이드 판정이 열립니다. 재사용 대기는 0.55초이며 키를 계속 누르는 것으로 반복 발동하지 않습니다. 이 가속에는 일반 회피의 무적이 붙지 않습니다.

적 크기는 적의 `MeleeCombatTarget → Body Size`에서 정합니다. 유효한 적에게 일반·저스트 슬라이딩 모두 기본 HP 피해 15를 한 번 전달합니다.

| 적 크기 | 일반 슬라이딩 | 저스트 슬라이드 중 접촉 |
| --- | --- | --- |
| 소형 | 적을 넘어뜨리고 통과. 접촉 순간 속력 90% 유지 | 적을 넘어뜨리고 통과. 접촉으로 인한 감속 없음 |
| 중형 | 적을 밀고 잠시 방해. 플레이어는 현재 슬라이딩 자세의 벽 충돌 반응 | 적을 넘어뜨리고 통과 |
| 대형 | 피해를 전달하되 밀지 않음. 플레이어는 현재 슬라이딩 자세의 벽 충돌 반응 | 적을 밀거나 넘어뜨리지 않고 플레이어가 회피처럼 통과 |

넘어짐·밀침은 대상이 실제 피해를 받은 경우 적용합니다. 한 번의 슬라이딩에서 같은 적을 여러 콜라이더로 만나거나 슬라이딩 자세가 바뀌어도 중복 피해를 주지 않습니다. 저스트 판정 중 통과한 적은 몸 밖으로 빠져나올 때까지 해당 적과의 몸 충돌만 잠시 무시합니다. 지면 마찰과 벽 충돌은 계속 적용됩니다.

### 벽 충돌과 레그돌

벽 반응은 기존 자세별 규칙을 유지합니다. 일반 슬라이딩은 충돌 속도에 따라 멈추거나 튕기며, 강한 반사는 누운 슬라이딩으로 이어질 수 있습니다. 비스듬한 접촉은 벽 방향으로 미끄러집니다. 머리부터·누운 슬라이딩의 정면 충돌은 해당 낮은 자세로 멈춥니다. 슬라이딩 공격은 돌진 밀치기의 피해나 히트스톱을 사용하지 않습니다.

적의 넘어짐은 실제 물리 반응입니다. 기본 넘어짐 시간은 1.2초입니다.

- 뼈대 레그돌이 없는 테스트 적은 몸통 Rigidbody와 콜라이더가 함께 쓰러집니다.
- 자식 Rigidbody와 Joint로 레그돌을 구성한 적은 뼈대 물리를 활성화합니다.
- 넘어지는 동안 Animator와 내비게이션을 멈추고 중력·회전 충격을 적용합니다. 바닥과 벽에 실제로 충돌합니다.
- 시간이 끝나도 발판이나 기립 공간이 없으면 쓰러진 상태를 유지합니다. 안전하게 설 수 있을 때 원래 본 자세·충돌체·Animator·내비게이션 상태를 복구합니다.

## 다이브

이동 중 Z로 도약합니다. 공중에서는 입력 방향으로 한 번 사용할 수 있으며, 입력이 없으면 전방을 사용합니다. 시선을 반대로 돌리면 전방/누운 자세를 바꿀 수 있지만, 추진력이나 체공 시간을 다시 얻지는 않습니다.

기본 수평 발사 속도는 9m/s입니다. 시작 0.25초 동안 속도를 유지한 뒤 부드럽게 감속하며, 착지하면 남은 운동량으로 머리부터·누운 슬라이딩에 연결됩니다. 착지 직후 0.55초 동안 새 다이브를 제한합니다. 다이브 자체에는 회피 무적이나 성공 보상이 없으며, 실제 몸의 이동·높이 변화로 공격을 피합니다.

상승과 엎드리는 느낌을 조절할 때는 `Player.csv`의 다음 `Move` 행부터 확인합니다.

| 행 | 조절하는 내용 |
| --- | --- |
| `groundDiveLaunchSpeed` / `groundDiveVerticalPop` | 수평 추진과 실제 상승력 |
| `divePoseDelay` / `divePoseDuration` | 몸과 눈높이가 낮아지기 시작하는 시점 / 걸리는 시간 |
| `diveSpeedHoldDuration` / `diveBurstDuration` / `diveBurstBraking` | 추진 유지 시간과 이후 감속 |
| `diveLandingRecovery` | 착지 후 재발동 대기 |
| `diveSlideFriction` / `supineSlideFriction` | 착지 뒤 미끄러짐의 감속 |

시점의 상승 느낌만 바꾸려면 `divePose*` 값을 먼저 조정합니다. `groundDiveVerticalPop`은 체공 시간과 이동거리까지 바꿉니다. 충분한 속도로 `IBreakable` 문에 부딪힌 슬라이딩·다이브는 문을 부수고 일부 속력을 유지할 수 있습니다.

## 스텝 회피와 기울이기

일반 회피는 지상 서기·앉기에서 시작합니다. 슬라이딩의 Alt는 앞에서 설명한 저스트 슬라이드 가속으로 처리합니다. 앉은 채 회피하면 앉은 자세로 미끄러지고, 앉기가 그대로 눌려 있거나 "눌러서 전환"으로 앉아 있었으면 회피가 끝나자마자 다시 앉습니다(회피하는 동안 Ctrl을 누르면 끝난 뒤의 자세가 바뀝니다). 스텝 회피는 화면에 흰 바람 줄기가 지나가고, 실제 공격을 피하면(스텝이든 Q/E든) 붉은 줄기·붉은 테두리로 번쩍이며 이어지는 반격 창의 테두리도 검붉습니다(포아너 참고, [DodgeFlash](../Scripts/Player/Movement/Dodge/DodgeFlash.cs)).

| 기능 | 기본값과 규칙 |
| --- | --- |
| Alt 스텝 | 2.6m / 0.14초 이동. 공격 회피 판정은 처음 0.18초 |
| Q/E 마이크로 회피 | 입력 직후 0.08초 판정. 키 유지로 기울인 자세 유지 가능 |
| Q/E 기울이기 | 눈이 옆으로 0.25m 가고 화면이 12° 기운다(`Ability.leanOffset`·`leanAngle`). 2026-11-11 "필요 이상으로 기울이는 것 같음"에 0.35m·18°에서 줄였다. 0.25m는 슬립이 비키는 거리(`Slip.clearance`)와 같아서 그보다 줄이면 슬립이 다 비키지 못한다 |
| Q/E 성공 반응 | 실제 공격을 회피했을 때만 슬립: 몸은 그대로 두고 눈이 원래 자리에서 누른 쪽으로 적어도 0.25m 비키며 6cm 숙인다(0.12초), 공격이 지나가는 0.48초 동안 머문 뒤 0.3초에 걸쳐 누르고 있는 기울기로 돌아온다. 그동안 시선이 공격한 적에게 붙어(시선에서 40° 안일 때) 머리가 비켜 나갔다 돌아와도 적이 화면 가운데에 있다(비켜 돌기). 마우스로 5° 돌리면 놓는다. 공격이 지나간 쪽 화면 가장자리가 0.35초 빛난다 |
| 재사용 대기 | 실패 시 스텝 1.25초 / 마이크로 0.55초. 서로 같은 대기 상태를 공유 |
| 성공 후 연결 | 실제 회피 성공 시 대기를 초기화. 새 Alt/Q/E 입력으로 다음 회피 가능. 반격이 달려드는 동안만은 회피가 나가지 않는다 |

Q/E 입력만으로도, 회피에 성공해도 플레이어 몸은 옆으로 이동하지 않습니다. 슬립은 기울기만 움직이므로 카메라, 몸의 휨, 상체 피격 볼륨, 다른 사람 화면이 기울이기와 똑같이 따라가고, 벽 가까이에서는 기울일 수 있는 만큼만 비킵니다. 이미 그보다 더 기울어 있으면 그 기울기를 그대로 둡니다. 숫자는 Player.csv의 Slip 행에 있습니다. 슬립하면 시선이 공격한 적에게 붙고, 그 뒤 곧은 주먹 반격은 달려드는 동안에도 그 적을 봅니다([WeaponSystemDesign](WeaponSystemDesign.md) §4).

스텝은 실제로 이동한 경로에 회피 성공을 인정하는 영역을 남깁니다. 몸보다 기본 0.12m 넓고 무적 시간 동안만 유효합니다. 이 영역에 공격이 스치면 성공 보상만 주며, 피해를 받는 몸이나 물리 충돌체가 되지는 않습니다. 한 공격 ID는 몸과 경로를 통틀어 한 번만 처리합니다.

스텝 중에는 적의 몸을 통과할 수 있습니다. Q/E 마이크로 회피는 몸을 옮기지 않으므로 적 몸과 계속 부딪히고, 판정이 끝날 때 옆으로 밀려나지도 않습니다. 스텝 종료 시 적과 겹쳐 있으면 벽·발판을 확인하며 안전한 출구를 찾습니다. 이 보정은 무적 시간을 늘리지 않습니다. Shift와 전진을 유지한 스텝이 정상적으로 끝나면 달리기를 이어갑니다.

## 파쿠르와 낙하

적의 몸과 자식 콜라이더는 벽 오르기·렛지 매달리기의 지지면으로 사용하지 않습니다. 매달린 채 적 쪽으로 옆 이동하는 것도 막습니다. 적 머리 위를 넘거나 올라서는 짧은 장애물 통과는 기존 조건대로 유지합니다.

| 상황 | 조작과 결과 |
| --- | --- |
| 지상의 장애물 | W + Space. 점프한 뒤 공중 판정이 넘기나 올라서기를 고른다. 할 수 있는 동작이 없으면 일반 점프. 허리 높이 장애물은 Beatrun에서는 몸 중심이 가까운 면에서 약 1.2m 안일 때 눌러야 넘는다. 여기서는 달리며 그보다 일찍 누른 점프면, 넘기가 걸리는 자리까지 `Ability.vaultSurgeDistance`(3m) 안이면 그 자리로 땅을 빠르게(`Ability.vaultSurgeSpeed` 최소 11m/s) 달려가 바로 넘는다. 달리기 동작도 빨라지고, 시작할 때 카메라가 살짝 앞으로 숙으며 시야각이 넓어진다(`Ability.vaultSurgeKick`). 넘기는 그 자리에 닿는 프레임에 땅에서 바로 시작하고, 누르기 전 달리던 속도로 한다. 그 자리에 닿았는데 지금 위치에서 다시 본 판정이 넘기를 놓치면(시선이 조금 돌았거나 장애물에 막혀 자리 바로 앞에서 멈춤), 그 자리에서 찾아 둔 넘기를 그대로 시작한다. 서지가 시작되면 W를 떼도 끝까지 달려가 넘는다. 시선이 60도 넘게 돌았거나 땅을 떠나면 원래대로 점프가 된다. 서지 속도로 들어가면 넘기가 빨리 감기처럼 보였고, 다음 프레임의 공중 판정에 맡기면 좁은 넘기 구간(레일은 약 0.65m)을 가끔 지나쳐 콩 볼트나 빠른 점프가 됐다. 몸보다 얕은 윗면(레일·얇은 벽)에는 올라서지 않고 넘기만 한다(`ParkourObstacle`의 Climb Onto는 예외). 점프가 오르는 동안 낮은 넘기는 Beatrun 점프가 지금쯤 발을 둘 높이에서 찾는다. 이 게임의 점프는 더 빨리 떠서, 60fps에서는 첫 공중 프레임에 이미 0.9m 레일을 찾는 높이를 지나 그냥 넘어가 버렸다 |
| 공중의 장애물 | W를 누른 채 다가가면 윗면 너머가 비었을 때 넘고, 막혀 있으면 올라탄다. 판정은 [Movement README](../Scripts/Player/Movement/README.md)에 있다. 떨어지며 렛지에 접근하면 자동 잡기 |
| 높은 곳에 올라서기 | 벽 앞에서 W를 누르고 있으면 얇은 벽 넘기, 높은 올라서기 순서로 시도한다. 둘 다 안 되면 렛지를 잡는다 |
| 벽 오르기와 넘기 | 이 점프로 곧 넘거나 올라설 수 있는 장애물이면 벽 오르기를 시작하지 않는다. 벽을 오르는 중에도 넘을 수 있게 되면 넘는다 |
| 넘기 끝의 점프 | 끝나는 순간 Space를 누르고 있으면 앞으로 튀어 오른다 |
| 넘기 끝의 착지 | 넘기는 장애물 너머 가슴 높이 공중에서 끝나는데, 발이 땅에 닿을 때까지 넘기 상태와 넘기 동작이 이어진다. 착지는 발 한가운데 아래의 바닥으로 판단해서, 캡슐 옆이 장애물 모서리에 스쳐도 착지로 치지 않는다. 낙하는 보통 낙하처럼 재서 착지 소리와 카메라 반동이 난다. 넘기처럼 캡슐을 자리로 옮기는 동작 뒤에는 컨트롤러의 '땅에 닿음' 값이 옮기기 전 것이라(땅에서 시작한 달려 넘기는 넘는 내내 '땅'으로 남는다), 모터는 다음 실제 이동 전까지 그 값을 믿지 않고 발밑 탐지로 판단한다. 넘기의 끝점과 일찍 끝내기는 몸 전체가 넘는 물체에서 빠졌을 때만 허락한다(`ParkourDetector.BodyClearOf`, 원본처럼 몸통을 바닥까지 검사). 예전 검사는 캡슐을 바닥에서 0.04m 띄워 했는데, 넘기 끝 발 높이 0.86m가 0.9m 레일 윗면 바로 아래라 몸 뒤가 레일에 걸친 채 끝났다. 그러면 레일 모서리에 2-3프레임 섰다가 0.8m를 떨어져, 넘기가 일찍 끊기고 걷기 상태로 바뀌어 보였다(2026-11-06 사용자 영상). 아래 땅이 60단위(약 1.46m)보다 깊으면 바로 낙하로 넘겨 착지 구르기를 쓰고, Ctrl을 누르면 그 자리에서 낙하로 넘긴다 |
| 렛지를 잡고 대기 | 벽을 본 상태에서 W를 놓았다가 다시 누르거나 Space로 올라가기 |
| 렛지 좌우 이동 | 벽을 향해 A/D. 가장자리 끝이나 막힌 옆 공간에서는 정지 |
| 렛지에서 방향 점프 | 벽 정면에서 기본 42도 넘게 시선을 돌린 뒤 Space |
| 렛지에서 내려오기 | Ctrl로 손 놓기 |
| 벽 오르기 | 공중에서 벽 정면을 향해 W + Space 유지로 진입. 올라가는 중이나 점프 꼭대기에서만 붙고 떨어지는 중에는 붙지 않는다. 한 번 오른 벽은 땅이나 렛지를 딛기 전에는 다시 오르지 않는다 |
| 벽에서 튕기기 | 벽 오르기 중 Space를 놓았다가 다시 누르기 |
| 공중의 봉 | 가까이서 W 또는 Space로 잡기. 유효한 봉을 일반 장애물보다 먼저 선택 |
| 봉 스윙 | W/S로 가속·감속 |
| 봉에서 도약 | 방향 입력 + Space로 스윙 운동량을 이어서 도약 |
| 봉 위에 올라가기 | 방향 입력 없이 Space. 지지 콜라이더와 위쪽 공간 필요 |
| 봉에서 내려오기 | Ctrl로 도약 보너스 없이 손 놓기 |
| 사다리 잡기 | 사다리를 정면(30도 안)으로 보고 W로 다가가기. 공중에서도 W를 누르고 있으면 잡는다. 총·주먹은 잠시 놓는다 |
| 사다리 타기 | W로 한 칸씩 오르고 S로 빠르게 미끄러져 내려오기. 땅에 닿으면 저절로 내려선다. Ctrl로 손 놓기 |
| 사다리 꼭대기 | 끝까지 오르면 디딜 바닥이 있을 때 저절로 넘어가 그 바닥에 선다. 바로 옆에 집라인이 있어도 잡지 않는다(잡으려면 Space로 뛴다) |
| 집라인 | 뛰어오른 공중(Space 점프, 넘기 끝 도약, 렛지 점프, 벽 차기, 봉에서 도약)이나 공중에서 Space를 누르고 있을 때 줄이 손에 닿으면 잡는다(발 위 1.44~3.6m, 옆으로 0.8m). 사다리 꼭대기·올라서기가 끝나 바닥 위에 잠깐 뜬 것, 걸어서 떨어지거나 손을 놓고 떨어지는 것, 맞아서 날아가는 것으로는 잡지 않는다. 도움닫기 속도로 출발해 기울기와 상관없이 18.75m/s까지 빨라진다. Ctrl이나 줄 끝에서 손을 놓으면 속도의 75%를 안고 날아간다 |
| 세게 착지 | 착지 전 `Ability.rollInputWindow`(0.5초) 안에 Ctrl을 누르고 구를 공간이 있으면 구른다. 낙하 피해와 감속이 없다 |

Ctrl을 유지한 공중 이동은 자동 파쿠르 진입을 막습니다. 벽 오르기에 이미 진입한 뒤에는 W/Space를 놓거나 시선을 돌려도 즉시 취소되지 않습니다. 한 번 오르는 시간은 `Ability.wallClimbTime`(1.5초)입니다. 처음엔 초당 키의 약 2.8배로 오르다 남은 시간에 맞춰 느려져 한 번에 키의 약 2.1배(약 3.7m)를 오릅니다. Beatrun의 수직 월 런과 같은 규칙입니다([WallClimbPace](../Scripts/Player/Movement/Parkour/WallClimbPace.cs)). 위로 뛰어오르는 중에 붙으면 조금 더 오래, 멈춰 서서 붙으면 조금 짧게 오릅니다. 끝나기로 한 때부터 2초 안에 다시 오르면 연달아 오른 것으로 세어 세 번째는 0.6배, 그 뒤로는 0.25배 시간만 오르고, 땅이나 렛지에서 다시 셉니다. 오르는 높이는 `Ability.wallClimbRate` 배율로 바꿉니다. 벽이 사라지거나 접촉·시간이 끝나면 이탈하고, 렛지에 도달하면 매달린 채 기다립니다. 벽을 옆으로 달리는 월 런은 구현되어 있지 않습니다.

낙하 피해와 착지 뒤의 동작은 [착지 단계](#착지-단계)에서 다룹니다. 낙하 피해는 일반 회피 무적으로는 막지 못합니다. 구르기는 발로 착지할 때만 됩니다. 다이브·포복·파쿠르 중이거나 기립·진행 공간이 부족하면 시작할 수 없습니다.

## 이동 감각

Beatrun의 손맛을 옮긴 부분입니다. 수치는 모두 [Player.csv](../Resources/Tables/Player.csv)에 있고 Play 중에도 바로 반영됩니다.

### 속도 쌓기

[MovementMomentum](../Scripts/Player/Movement/Actions/MovementMomentum.cs)이 맡고 수치는 `Move` 행입니다. 디버그 HUD의 `run`이 지금 쌓인 속도입니다.

| 입력 | 속도 변화 |
| --- | --- |
| W만 | `runStartSpeed` 3.8m/s에서 출발. `walkBuildTime` 1초에 걷기 속도 5.2, `sprintBuildTime` 3.5초에 질주 속도 8.4, 그 뒤 `topBuildTime` 2초에 걸쳐 `topSpeed` 9.5 |
| Shift + W | 0.1초 만에 8.4. 거기서부터 9.5까지 쌓인다 |
| 옆·뒤 | 걷기 속도까지만 |

쌓인 속도는 다음 경우에 줄어듭니다.

- 앞으로 달리기를 멈추면 `momentumFalloff`로 빠집니다.
- 시선을 `turnCutRate`보다 빠르게 돌리면 돈 각도만큼(`turnCutPerDegree`) 깎입니다.
- 벽에 막히면 실제 속도로 깎입니다.
- 발로 세게·크게 착지하거나, 적에 부딪혀 돌진 밀치기가 멈추면 출발 속도로 깎입니다.

공중에서는 유지됩니다. 슬라이드·구르기·넘기 등에서 서기로 돌아오면 그때 실제로 움직이던 속도에서 이어 갑니다. 회피와 빗나간 돌진 밀치기는 하던 달리기를 그대로 둡니다.

### 계단·경사 내려가기

[MovementMotor](../Scripts/Player/Movement/Core/MovementMotor.cs)는 땅에 있던 캡슐이 이동 후 발밑을 잃으면, 캡슐 스텝 높이(0.3m)+0.05m 안의 걸을 수 있는 땅으로 바로 내려붙입니다. 빠르게 계단을 내려가도 칸마다 공중에 떴다 착지하지 않으므로 착지 소리와 펀치가 칸마다 나지 않습니다. 그보다 높은 턱은 그대로 떨어집니다.

### 가장자리의 접지

기존 캡슐의 접촉과 걸침을 유지합니다. 중심 바로 아래의 바닥을 의무로 요구하거나 가장자리에서 플레이어를 바깥으로 밀지 않습니다. 계단 내려붙이기와 슬라이딩도 기존 캡슐 검사를 사용합니다.

발의 수평 위치는 걷는 애니메이션을 따릅니다. 발 IK는 경사·계단의 높이와 기울기만 보정하고, 발밑을 놓치면 마지막 보정의 영향이 `Body.footSettleTime`에 걸쳐 풀립니다. 지지가 없는 발은 발소리를 내지 않습니다.

### 착지 단계

낙하 속도는 실제 캡슐 하강 거리로 계산한 속도를 상한으로 삼습니다. 턱·벽에 걸려 내려가지 못한 시간은 충격으로 쌓이지 않습니다. 공중 자세 변경에 따른 캡슐 기준점 보정도 낙하 거리에서 제외합니다. 몸의 빠른 낙하 자세·큰 낙하 연출·착지 소리·카메라 충격은 이 판정을 공유합니다. 실제 높은 낙하와 명시적인 아래 방향 넉백의 충격은 유지하며, 봉·집라인 이탈 때 이미 아래로 움직이던 속도도 반영합니다.

[MovementLanding](../Scripts/Player/Movement/Actions/MovementLanding.cs)이 단계를 정하고 수치는 `Ability` 행입니다. 디버그 HUD의 `Last landing`에 마지막 착지의 단계·속도·높이가 나옵니다. 중력 24에서 12m/s는 약 3m, 16m/s는 약 5.3m, 26m/s는 약 14m 낙하입니다.

| 단계 | 조건 | 결과 |
| --- | --- | --- |
| 가볍게 | `hardLandingSpeed` 12m/s 미만 | 몸·소리·펀치만 낙하 속도에 맞춰진다 |
| 세게 (Beatrun) | 12m/s 이상으로 발로 착지 | 쌓인 속도가 출발 속도로 깎이고, 이동 속도가 `hardLandingMoveScale`(0.1)배에서 `hardLandingRecoverTime`(1초)에 걸쳐 돌아온다. `hardLandingNoSprintTime`(0.5초) 동안 달려서 속도를 쌓지 못한다. 점프·회피는 된다. 소리는 `LandHard` |
| 크게 (Dynamic Landing) | `safeFallSpeed` 16m/s 초과 + `safeFallDistance` 4m 초과 | 넘은 1m/s당 `fallDamagePerSpeed`의 낙하 피해 뒤 `HeavyLanding` 상태로 쓰러졌다 일어난다. 그동안 시선만 돌고 이동·점프·공격·조준은 안 된다. 미끄러지던 속도는 `heavyLandingBraking`으로 금방 멈춘다. 소리는 `LandHeavy`, 일어날 때 `GetUp`(`MovementAudio.getUpShare`) |

크게 착지할 때의 자세는 움직임으로 정해집니다.

| 자세 | 조건 | 시간 |
| --- | --- | --- |
| 등으로 | 시선 반대쪽으로 `backLandingMinSpeed`(0.4m/s) 넘게 움직이는 중 | `backLandingTime` 2.8초 |
| 엎어짐 | `faceDownLandingSpeed`(26m/s)보다 빠름 | `faceDownLandingTime` 1.5초 |
| 손과 무릎 | 그 밖의 경우 | `heavyLandingTime` 1.6초 |

- **착지 슬라이드**: Ctrl을 누른 채 빠르게 착지해 슬라이드가 되면 세게 착지의 감속이 없습니다.
- **구르기**: 세게·크게 착지하기 전 `rollInputWindow`(0.5초) 안에 Ctrl을 누르면 구릅니다. 피해·감속 없이 속도를 그대로 가져갑니다. 앞이 막혔거나 천장이 낮으면 구르지 못합니다. 수평 속도가 `rollLandSpeed`(2m/s)보다 느리거나 S를 누르고 있으면 구르지 않고 `rollLandTime`(0.6초) 동안 멈춰 제자리에 착지합니다. 피해가 없는 것은 같습니다. Beatrun의 기준(200단위/초, 약 4.9m/s)은 걷기 속도와 같아서 걷다가 떨어지면 늘 제자리 착지였고, 걸어도 구르도록 걷기 출발 속도(3.6m/s)보다 낮췄습니다(2026-11-06 사용자 요청).
- **넉백 훅**: `PlayerMovement.KnockBack(velocity)`는 큰 적의 일격용이며 위쪽 성분을 넣어 씁니다. 날아가는 동안 조작이 안 되고, 착지하면 다치지 않았어도 맞은 쪽을 보고 등으로 쓰러졌다 일어납니다. 낙하 피해는 평소 규칙대로만 받습니다. 땅에서 위로 띄우지 않는 넉백은 그 자리에서 쓰러집니다.

### 시점 펀치

[PlayerMovementPunch](../Scripts/Player/Camera/PlayerMovementPunch.cs)가 맡고 수치는 `Punch` 행입니다. Source 엔진의 펀치 스프링(65·9·20)에 Beatrun 값을 그대로 옮겼습니다.

- 발이 땅에 닿을 때마다(`PlayerFootsteps.Stepped`) 살짝 끄덕이고 디딘 발 쪽으로 기울어서 좌우가 번갈아 바뀝니다. 빠를수록 덜 기울고, 속도가 쌓이는 중에는 더 세며, 총을 들면 줄어듭니다.
- 앞으로 달리며 점프하면 시점이 들리고, 착지하면 낙하 속도에 비례해 끄덕임:기울기 2:1로 숙여집니다.
- 세게·크게 착지하면 Beatrun hardland 펀치(`hardLandPunch` 10;2;5)가 더해집니다.
- 웅크린 걸음과 구르기 착지는 펀치가 없습니다. 구르기는 자기 연출이 있습니다.

Esc 메뉴 **화면 흔들림**이 곱해집니다.

### 바람

[PlayerWindAudio](../Scripts/Player/Audio/PlayerWindAudio.cs)가 맡고 수치는 `Wind` 행입니다. `Movement/Wind/Run`·`Wind/Cloth`가 이동 속도(떨어지는 속도 포함)에 따라 커집니다. 최고 달리기 속도에서는 작게, 큰 낙하에서는 크게 들립니다.

### 큰 낙하

낙하 꼭대기부터 아래 땅까지 `Ability.bigFallHeight`(8.5m)를 넘고 `bigFallMinSpeed`(9m/s)보다 빠르게 떨어지면 큰 낙하입니다. 땅이 멀면 떨어지기 시작하자마자 들어가고, 틈을 건너뛰는 점프는 해당되지 않습니다. 착지·난간 잡기·다이브에서 끝납니다. 마우스 조작은 막지 않습니다.

- **소리**([PlayerFallAudio](../Scripts/Player/Audio/PlayerFallAudio.cs), `FallAudio` 행): 지지직 바람(`Fall/Static`)이 반복되고, 0.5초 뒤부터 심장이 뜁니다. 박동마다 조금씩 커지고 빨리 떨어질수록 빨라집니다. 박동 한 번은 [SoundCues.csv](../Resources/Tables/SoundCues.csv)의 `FallHeartbeat`입니다.
- **화면**([PlayerFallScreen](../Scripts/Player/Camera/PlayerFallScreen.cs), `FallScreen` 행): 가장자리만 렌즈처럼 휘고(숨 쉬듯 줄었다 늘었다), 색이 번지고, 어두워집니다. 가운데는 그대로입니다. `rampTime`(2초)에 걸쳐 들어오고 착지하면 `clearTime`에 사라집니다.
- **몸**: `Body.fallFlail`로 허우적거립니다. 큰 낙하 중 Ctrl은 착지 구르기만 준비합니다.

## 사다리·집라인

Beatrun의 `br_ladder`·`br_zipline`을 옮긴 월드 오브젝트입니다. 조작은 위 [파쿠르와 낙하](#파쿠르와-낙하) 표에 있습니다. 수치는 `Player.csv`의 `Ability.ladder*`·`Ability.zipline*` 행, 클립은 `Body` 행, 소리는 `FixtureAudio` 행과 [SoundCues.csv](../Resources/Tables/SoundCues.csv)의 `Ladder*`·`Zipline*` 큐입니다. 시험장은 [MovementAbilityPlayground](../Scenes/Development/MovementAbilityPlayground.unity)의 `Ladder`(`Roll drop platform` 앞면), `Zipline`(그 플랫폼 위에서 점프)입니다.

사다리·집라인은 파쿠르 상태라 그동안 총과 주먹을 쓸 수 없습니다.

### 씬에 넣기

| 넣을 것 | 방법 |
| --- | --- |
| 사다리 | 빈 오브젝트에 [Ladder](../Scripts/World/Ladder.cs)를 붙여 사다리 발치, 가로대 면에 놓는다. 로컬 Z는 오르는 사람 쪽(벽 바깥)이다. `height`는 오르는 바닥(지붕·발판)의 높이로, 난간 끝이 그 바닥과 같게 둔다(발은 꼭대기 1.875m 아래까지 오르고 넘어가기가 나머지를 올려 준다. 지붕 위로 솟은 난간은 필요 없다). 맵 빌더(CampaignMaps·HubBuilder)는 발치와 방향만 적고 높이는 지을 때 [LadderFit](../Editor/World/LadderFit.cs)이 잰다: 가로대 면에서 0.6m 안쪽(넘어가기가 디딜 바닥을 찾는 자리, `ladderExitReach - ladderStandOff`)에서 발치 위의 첫 바닥, 그 위에 설 자리가 있어야 한다. 가로대 면을 벽에서 0.15m쯤 띄운다. 콜라이더는 없어도 된다 |
| 집라인 | 빈 오브젝트에 [Zipline](../Scripts/World/Zipline.cs)을 붙여 줄 시작점에 놓고 `end`에 끝점을 적는다. 발이 줄 1.875m 아래에 매달리므로 끝점은 땅에서 그보다 높게 둔다. 놓을 때 빠른 속도로 날아가니 끝점 앞에 공간을 둔다. 양방향은 `twoWay` |

사다리와 집라인은 자식에 렌더러가 없으면 Play 때 `barMaterial`로 막대를 그립니다([FixtureBars](../Scripts/World/FixtureBars.cs)). 모델을 자식으로 넣으면 막대는 생기지 않습니다. 씬 뷰에서는 기즈모(사다리 노랑, 줄 하늘색)로 보입니다.
