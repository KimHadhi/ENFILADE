# 이동·파쿠르·회피 사용 안내

현재 코드와 입력 에셋을 기준으로 정리했다. 아래 수치는 기본값이며 씬의 인스펙터 설정이 우선한다. 수정할 파일은 [스크립트 길잡이](../Scripts/README.md)에서 찾을 수 있다.

## 기본 이동·자세

| 기능 | 조작과 동작 |
| --- | --- |
| 걷기·횡이동 | WASD. 기본 걷기 5.2m/s, 횡이동 보정 1.15배. 지상 가속/감속과 공중 조향을 구분 |
| 전력 질주 | Shift + 전진. 기본 8.4m/s까지 가속하며, 정지 상태에서 즉시 최고 속도가 되는 것을 완화 |
| 점프 | Space. 기본 점프 높이 1.3m. 지형 통과가 가능하면 Vault/Mantle이 우선 |
| 점프 입력 보정 | 발판 이탈 후 0.1초 코요테 타임, 착지 직전 0.15초 점프 버퍼 |
| 앉기 | Ctrl 유지. 키를 놓으면 머리 위 공간이 있을 때 기립 |
| 공중 웅크리기 | 공중에서 Ctrl로 몸을 접는다. 머리 높이를 유지하며 다리 쪽 캡슐을 줄이고, 착지 시 발 기준을 복구 |
| 포복 | 앉아서 Z. 기본 1.6m/s. 앉아 이동할 때 기본 0.6m 앞의 낮은 통로를 감지하여 자동 포복. 높이 1m 통로도 포복으로 진입 |
| 포복에서 기상 | Space는 먼저 일어나기. Ctrl/Z 재입력으로 자세 전환, Shift + 이동으로 빠르게 기상. 천장이 막히면 가능한 낮은 자세 유지 |
| 누운 자세 | 뒤로 다이브/슬라이드가 끝나면 진입. A/D로 좌우, S 및 뒤 대각선으로 이동. 누운 슬라이드 중에는 기존 조향을 유지하며 W로 기상하지 않음. 슬라이드가 끝난 Supine 상태에서만 지상 W로 기상하며, 천장이 낮으면 앉거나 누운 자세를 유지. 기존 포복 기상 입력도 사용 가능 |
| 낮은 단차 | 기본 0.3m 이하의 계단·턱은 점프 없이 올라감 |
| 머리 공간 검사 | 앉기는 캡슐 높이 외에 기본 0.15m 머리 여유를 요구하므로 1m 통로 안에서는 포복 유지. 현재 포복 폭이 아닌 앉을 때의 전체 캡슐 폭으로 검사. 환풍구에서 빠져나올 때 앞쪽 여유 공간도 확인 |

## 슬라이딩·다이빙

| 기능 | 조작과 동작 |
| --- | --- |
| 일반 슬라이드 | 실제 달리기 속도가 충분할 때 Shift + 전진 상태에서 Ctrl을 새로 누름. 시작 시 추진력 추가 |
| 경사면 타기 | 기본 최대 65도 경사를 지원. 내리막은 가속, 오르막은 감속. 계단과 경사에서 바닥 밀착, 절벽/점프에서는 접지 해제 |
| 슬라이드 조향 | A/D로 제한적으로 방향을 조절. 벽을 비스듬히 스치면 벽을 따라 속도를 투영 |
| 슬라이드 브레이크 | 진행 방향의 반대 입력, 또는 Ctrl을 놓았다가 다시 눌러 제동. 진입 때부터 Ctrl을 유지한 것은 즉시 브레이크로 취급하지 않음 |
| 슬라이드 종료 | 감속하면 서기/앉기/포복 중 공간과 입력에 맞는 자세로 전환. 충분히 느려지고 최소 시간이 지나면 Shift + 전진으로 기상 |
| 슬라이드 점프 | 일반 슬라이드에서 최소 0.1초 후 Space. 현재 속도 + 0.8m/s, 최소 3m/s의 수평 속도로 다이브 도약. 머리부터/누운 슬라이드에서는 이 점프를 허용하지 않음 |
| 전방·측방 다이브 | 이동 + Z. 지상 제자리 Z는 포복 유지. 공중 Z는 입력 방향(없으면 전방)으로 한 번만 다이브. 지상·공중의 수평 추진 규칙은 동일 |
| 뒤로 다이브 | 뒤 방향 입력 + Z. 누운 다이브. 비행 중 시선을 몸의 반대쪽으로 돌리면 전방/누운 다이브 자세를 전환 |
| 다이브 비행 | 기본 9m/s로 도약하고 0.25초간 수평 속도를 유지한 뒤 0.1초에 걸쳐 감속 강도를 서서히 높여 2.2m/s 쪽으로 감속. 중력 배율 0.9, 제한적인 A/D 조향. 고개를 돌려도 추진력이나 체공 시간을 다시 얻지 않음 |
| 다이브 착지 | 남은 운동량으로 머리부터 또는 누운 슬라이드에 연결한 뒤 포복/누운 자세로 정지. 실제 착지 후 0.55초 동안 새 다이브는 차단. 조준은 계속 가능 |
| 벽 충돌 반응 | 일반 슬라이드는 충돌 속도에 따라 정지/반사, 강한 반사 시 누운 슬라이드. 머리부터/누운 슬라이드는 정면 충돌 시 해당 낮은 자세로 정지 |
| 문 부수기 | 일정 속도 이상의 슬라이드·다이브 또는 태클이 IBreakable 문에 충돌하면 파괴. 일반 슬라이드/다이브는 파괴 후 속도 일부 유지 |

## 회피·파쿠르·전투 연계 조작

### 다이브의 목적과 레퍼런스

다이브는 장거리 이동보다 순간적인 몸의 위치·자세 변경에 초점을 둔다. @bushsoftware의 [제공된 무기/게임플레이 영상](https://www.youtube.com/shorts/OVn5ebOz0d4)과 [추가 게임플레이 영상](https://www.youtube.com/shorts/AszQwodqxOs)의 공중 조준, 기울어진 시점, 낮은 착지 자세를 브라우저에서 확인해 참고했다. 수치와 물리 코드를 영상에서 추출한 것은 아니며, 아래 값은 Morphang을 위한 조정값이다.

- 지상 수직 발사 속도 4.6m/s. 공중 다이브는 기존 상승 속도를 유지하거나 최대 1.61m/s까지 들어 올리는 한 번의 발사이며, 별도 공중 재발동은 없다.
- 시작 0.25초는 수평 속도를 유지한다. 이후 0.1초 동안 감속 강도를 0에서 2.6까지 서서히 높이고, 수평 속도를 2.2m/s 쪽으로 완만하게 줄인다. 특정 시점에 강한 감속을 켜지 않으므로 하강 중에도 전진이 이어진다. 일반 Z 다이브의 진입 수평 속도는 발사 속도의 110%(기본 9.9m/s)로 제한하여 회피 추진력이 다이브에 과도하게 누적되지 않게 한다. 착지 때 속도를 즉시 자르거나 추가 가속하지 않고, 기본 마찰 9로 미끄러지며 멈춘다.
- 도약 직후 0.03초 뒤부터 0.5초에 걸쳐 몸과 카메라를 함께 엎드린 높이로 낮춘다. 상승 정점에 자세 하강이 몰리지 않도록 긴 곡선으로 연결했다. 카메라의 작은 피치/롤 효과는 마우스 조준과 분리된다. 낮은 천장에서는 캡슐 충돌로 상승이 멈춘다.
- 앞/뒤 자세 전환은 같은 비행 동작의 일부다. 시선을 돌려 자세가 바뀌어도 추진 구간을 다시 시작하지 않는다. 정점에서 잠깐 수직 속도가 0이 되거나 벽에 막혀도 공중 포복으로 조기 종료하지 않는다.
- 다이브 자체에는 무적과 회피 쿨타임 환급이 없다. Alt/Q/E의 기존 무적 회피와 별개이며, 실제 충돌 캡슐의 이동·축소로 공격을 피한다.
- 기본값의 평지 검사: 30/60/120Hz에서 약 0.43초, 착지까지 약 3.72~3.74m, 착지 후 정리까지 약 6.40~6.43m. 6초간 즉시 기상·재발동을 반복한 다이브 약 37.4m, 전력 질주 약 50.4m. 8초간 스텝 닷지와 다이브를 번갈아 사용하면 약 53.1~55.6m, 전력 질주는 약 67.2m다(공격 회피 성공에 따른 쿨타임 초기화 제외). 이는 테스트용 평지 측정이며 경사·높이·진입 속도에 따라 달라진다.
- 서서 시작하는 전후좌우 다이브의 눈높이는 약 0.12~0.13초에 정점에 도달하며, 시작보다 약 0.30~0.34m 올라간 뒤 낮은 착지 자세로 내려온다. 첨부된 `a.mp4`와 이후 궤적 스케치의 상승·하강 흐름을 참고한 조정이며 영상의 정확한 물리 수치를 복제한 것은 아니다.
- 영상의 팔·다리·무기 모델/애니메이션은 포함하지 않는다. 모델 연출을 연결할 때 `MovementDive.EntrySerial`과 `BurstWeight`, 현재 이동 자세를 사용할 수 있다.

추진/감속/회복은 `PlayerMovement.Configuration`의 Dive 설정과 `Actions/MovementDive.cs`, 자세/착지는 `States/Diving/`, 화면 효과는 `PlayerCameraEffects`에서 조정한다.

**다이브 상승 느낌 조절**: PlayerMovement 인스펙터의 `Dive Pose Delay`는 몸을 눕히기 전 대기 시간, `Dive Pose Duration`은 눕는 데 걸리는 시간이다. 두 값은 `Core/MovementPostureController.cs`에서 캡슐과 카메라에 함께 적용된다. Delay를 늘리면 상승을 더 오래 보여 주고, Duration을 늘리면 더 천천히 눕는다. 두 값의 합을 비행 시간보다 많이 늘리면 착지 후에도 자세가 내려오는 느낌이 날 수 있다. 실제 상승력은 `Ground Dive Vertical Pop`이다. 이는 체공 시간과 이동거리도 바꾸므로 시점만 조정할 때는 Pose 값부터 수정한다.


| 입력 | 동작 |
| --- | --- |
| 지상 이동 + Space | 전방 단차를 검사하여 Vault 또는 Mantle. 유효한 대상이 없으면 기존 점프 |
| 공중에서 W로 장애물에 접근 | 발 기준 높이 1.15m 이내의 넘을 수 있는 장애물은 렛지 대기 없이 바로 Vault/올라타기. 높은 턱은 Space 재입력으로 직접 Mantle 시도 가능 |
| 이동만 | 설정된 Step Height 이하의 계단/턱 통과 |
| Alt + 이동 방향 | 기본 2m / 0.14초 스텝 닷지. 방향 입력이 없으면 뒤로 이동. 무적은 이동 종료와 별개로 처음 0.18초 유지 |
| Q / E | 좌/우 기울이기와 짧은 마이크로 닷지 무적 |
| Q/E 회피 성공 | 해당 무적으로 실제 공격을 막았을 때만 기울인 쪽으로 0.3m 이동. 발동당 한 번 |
| 공중에서 전진 + Space 유지 | 정면 벽 클라이밍. 사용 가능한 봉이 가까우면 봉 잡기 우선 |
| 떨어지면서 전방 렛지에 접근 | 손 높이의 잡을 수 있는 렛지를 자동으로 잡고 대기. Ctrl 유지 중에는 자동 잡기 안 함 |
| 월 클라이밍으로 렛지 도달 | 자동으로 매달리기 상태에서 대기. W/Space를 계속 누르고 있어도 바로 올라가지 않음 |
| 렛지에서 벽을 보며 W / Space 새로 누르기 | 머리 위와 도착 공간이 있으면 Mantle. W는 한 번 놓고 다시 누르기 |
| 렛지에서 벽 정면 기준 42도 넘게 시선을 돌린 뒤 Space | 바라보는 쪽으로 위로 튕겨 나가기. 옆으로 뛸 때도 벽에 박히지 않도록 바깥 방향으로 분리 |
| 렛지에서 A/D | 벽 정면 기준 42도 안쪽을 볼 때만 가장자리를 따라 좌우 이동. 지지할 가장자리가 끝나거나 옆이 막히면 멈춤 |
| 렛지에서 벽 정면 기준 42도 넘게 시선 돌리기 | 방향 점프 준비. A/D와 전진으로 매달린 위치를 움직이지 않으며, Space로 바라보는 쪽으로 도약. 벽 쪽으로 다시 보면 좌우 이동 재개 |
| 렛지에서 Ctrl | 손 놓기. 짧은 재부착 제한으로 바로 다시 잡지 않음 |
| 벽 동작 중 Space 다시 누르기 | 월 킥. Space를 놓아도 바로 떨어지지 않으므로 다시 누를 수 있음 |
| 벽 동작 중 W/Space 놓기·시선 변경·Ctrl | 동작 유지. Space를 새로 누르면 월 킥 |
| 공중에서 봉 근처 + W 또는 Space | 일반 렛지·Vault보다 봉 잡기 우선. 봉 Collider는 일반 렛지·벽·Vault 대상으로 취급하지 않음 |
| 봉에서 W/S | 스윙 가속/감속. 방향은 플레이어의 이동 입력과 봉의 스윙 방향을 기준으로 계산 |
| 봉에서 이동 입력 + Space 새로 누르기 | 스윙 운동량을 유지한 라셰 도약 |
| 봉에서 이동 입력 없이 Space 새로 누르기 | 봉 위에 Mantle. 봉에 실제 지지 Collider와 위쪽 공간이 있어야 함. 막혀 있으면 봉을 계속 잡음 |
| 봉에서 Ctrl | 도약 보너스 없이 손 놓기 |
| 위험한 착지 직전 Ctrl 새로 누르기 | 0.22초 이내 착지 + 구를 공간이 있으면 롤링, 해당 낙하 피해 취소 |
| V | 현재 입력 에셋의 밀치기 키. 전진 스프린트 실제 속도 6m/s 이상이면 태클 |
| Z | 기존 다이빙 유지 |

Space는 상태에 따라 한 번만 소비한다. 특수 동작 중에는 일반 점프 버퍼가 중복 발동하지 않는다.
마이크로 닷지/스텝 닷지는 지상 서기·앉기에서만 시작한다. 벽/봉/장애물 통과·슬라이드·다이브·롤링·태클 중에는 차단한다.

Q/E를 눌렀거나 유지하는 것만으로 캐릭터 위치는 변하지 않는다. 기본 기울임은 10°, 카메라 수평 이동은 0.35m다. 기울임 반응을 완만하게 하고, 회전 때문에 카메라 높이가 함께 내려가지 않도록 수평 이동을 분리했다. 벽 옆에서는 최종 카메라 위치까지 충돌 검사를 하여 관통을 막는다. 몸의 이동은 **확인된 공격의 무적 차단** 뒤에만 일어난다.
무적 시간이 끝난 뒤에도 기울인 자세는 유지할 수 있다. 좌우와 Alt는 재사용 시간을 공유하므로 입력을 바꿔 무적을 연장할 수 없다.
단, 스텝/마이크로 닷지에 **실제로 회피 성공 판정이 나면 공유 쿨타임이 즉시 0**이 된다. 성공 뒤에는 기존 무적 시간이 남았어도 새 Alt/Q/E 입력으로 다음 회피를 시작할 수 있다. 키를 계속 누르는 것만으로는 재발동하지 않는다. 실패하면 발동 기준 스텝 1.25초(`Step Dodge Cooldown`), 마이크로 0.55초(`Dodge Cooldown`)의 재사용 대기를 유지한다.

Shift와 전진을 유지한 스텝 닷지는 달리기 가속을 잃지 않는다. 정상 완료 시 현재 이동 입력 방향으로 달리기를 이어 가며 Shift를 다시 누를 필요가 없다. 도중에 Shift를 떼면 일반 이동으로 복귀하고, 벽 충돌·공중 이탈로 중단되면 달리기 속도를 강제로 복구하지 않는다. 달리기는 새 누름 이벤트가 아닌 현재 바인딩된 버튼의 유지 상태를 읽는다.
벽에 막히면 횡이동은 가능한 만큼만 적용된다. 키를 놓을 때 이동한 위치를 되돌리지는 않는다.

### 스텝 닷지의 관대한 성공 인정

스텝 닷지는 출발점부터 **실제 이동한 경로 전체**에 몸 캡슐보다 바깥쪽으로 기본 0.12m 넓은 회피 인정 영역을 남긴다. 공격이 현재 몸을 빗나가도 이 영역과 닿으면 성공으로 처리하고 쿨타임을 초기화한다. 기본 유효 시간은 스텝의 기존 무적 시간 0.18초이며, 이동 거리 2m/이동 시간 0.14초와 독립적이다.

이 영역은 피해를 받는 몸이나 물리 충돌체가 아니다. 접촉은 성공 보상만 발생시키며 체력을 깎지 않는다. 실제 몸에 들어온 공격은 기존 피해/무적 판정을 사용한다. 마이크로 닷지는 경로 영역 없이 기존 몸 무적으로 회피한 경우만 성공한다. Q/E의 성공 후 짧은 횡이동도 유지한다.

한 번의 공격 ID는 몸과 경로 영역을 통틀어 한 번만 처리한다. 긴 휘두르기나 여러 히트박스에 같은 ID를 사용하면 동일 공격으로 연속 초기화할 수 없다. 다음 회피에서 다른 공격을 피하면 다시 초기화된다. 벽에 막히면 실제 도달한 지점까지만 경로를 기록하고, 중단·무적 종료·사망·초기화 시 영역은 사라진다. 새 스텝을 시작하면 이전 경로는 교체된다.

## 설정과 구조

기존 PlayerMovement 컴포넌트의 **Ability Settings**에서 새 기능의 거리·속도·지속시간·무적 시간·공유 쿨다운을 조정한다.
낮은 통로 판정은 PlayerMovement의 **Crouch Clearance Margin**(기본 0.15m)과 **Prone Entry Look Ahead**(기본 0.6m)에서 조정한다. 실제 앉기 캡슐 높이는 유지한다. 기본 앉기 높이 0.9m에 여유를 더해 약 1.05m보다 넉넉한 공간에서만 앉기를 허용한다. 자동 포복은 실제로 낮은 고정 천장이 있고, 여유를 둔 포복 캡슐 전체와 진입 경로가 모두 비어 있을 때만 허용한다. 옆 벽, 막힌 경로, 포복보다 좁거나 낮은 틈, 리지드바디 또는 밀칠 수 있는 물체는 자동 포복용 천장으로 인정하지 않는다. 태클 중에는 자동 포복을 차단하며, 태클 종료 시 머리 공간이 막혔다면 앉기로 전환한다. Ctrl을 유지해도 안에서 자세를 반복 전환하지 않고, 출구에서 몸 전체가 빠져나온 뒤 앉기로 복귀한다.
기존 9개 상태 enum의 값과 사용하는 설정 필드는 유지하고 새 상태는 enum 뒤에 추가했다. 실제로 읽지 않던 다이브 설정 3개는 정리했다.

- `MovementAbilities`: 새 행동의 시작 우선순위와 각 기능 연결.
- `DodgeController`: Alt/Q/E가 공유하는 무적·재사용 시간·회피 성공 이벤트.
- `StepDodgeTrail`: 스텝 닷지의 실제 이동 경로와 보상 전용 확대 판정. `Step Dodge Recognition Padding`으로 여유 폭 조정.
- `MovementLean`: 기울이기와 마이크로 닷지 성공 후 한 번의 횡이동.
- `ParkourDetector`: 장애물 높이/깊이/경로/도착 공간, 벽, 봉 탐지.
- `ParkourTraversal`: 벽 사용 시간, 현재 봉/벽/목표, 도약 정보.
- `MovementLanding`: 충돌 직전 하강 속도, 롤링 예약, 착지 피해의 단일 처리.
- `PlayerCombatActions`: 밀치기·태클과 대상별 공격 중복 방지. Player/Combat 폴더에 위치.
- `PlayerDamageReceiver`: 체력, 공격 중복 제거, 공통 회피 판정, 사망 이벤트.

실제 위치 변경은 MovementMotor가 담당한다. 일반 이동과 높은 렛지/봉 맨틀은 CharacterController.Move를 사용한다. 낮은 Vault/올라타기는 서 있는 캡슐 경로를 검사한 뒤 원본처럼 직접 위치를 보간한다. 이때 선택한 장애물 하나만 통과하며, 다른 벽과 천장은 통과하지 않는다.
월 런은 제거했다. 월 클라이밍은 벽 정면을 향해 공중에서 W + Space를 유지할 때 시작하고, 기본 1.8초의 공중 사용 시간을 소모한다. 벽을 바꿔도 충전되지 않으며 정상 접지에서 충전한다. 옆 벽을 따라 이동하는 것만으로 벽에 붙거나 가속하지 않는다.
짧은 접촉 끊김은 0.1초 동안 허용하지만, 실제 벽 끝이나 사라진 벽에서는 종료한다.
벽 정면을 향한 W + Space는 클라이밍 진입 조건이다. 시작한 뒤에는 입력 해제, 시선 변경, Ctrl로 취소되지 않는다. 클라이밍 중 수평 시야는 벽을 향한 방향 기준 좌우 30°로 제한하며, 종료하면 즉시 자유 시야로 복귀한다. 렛지 행의 시야 규칙은 별도로 유지한다.
벽 소멸·접촉 상실·공유 시간 소진 시에는 종료한다. Space를 새로 누르면 월 킥, 정상 도달하면 렛지로 전환한다.
렛지 매달리기는 벽 이동 시간을 소모하지 않는다. 위가 막혀 맨틀할 수 없으면 매달린 채로 기다린다.
슬라이딩은 기본 65도까지 경사를 지원하고 내리막에서 접지와 가속을 유지한다. 절벽 이탈과 점프에는 접지를 해제한다.
낮은 Vault/올라타기는 시작점과 목표점 사이를 직선으로 이동한다. 먼저 수직으로 들었다가 앞으로 이동하는 곡선과 강제 앉기를 사용하지 않는다. 높은 렛지와 봉 맨틀은 기존의 충돌을 피하는 경로를 유지한다.
Vault2의 기본 목표는 시작점에서 전방 1.75m, 위 0.8m다. 이 위치가 막히면 실제로 검사한 장애물 너머 위치를 사용한다. 낮은 넓은 발판의 Vault1 목표는 전방 1.25m 지점의 발판 위 0.4m다. 실제 착지는 일반 중력이 처리한다.
공중 진입 우선순위는 봉 잡기 → 넘을 수 있는 낮은 장애물 → 렛지 잡기 → 벽 이동이다. 빠른 추락 중에는 자동 올라타기를 하지 않는다.
월 클라이밍으로 손 높이의 렛지에 도달했을 때는 기존처럼 매달려 기다린다.
진행률은 마지막 첨부한 `vmanip_vault`를 기준으로 한다. 기준 주파수 66.66Hz에서 Vault 보간율 0.1, Mantle 0.075를 프레임 시간에 맞춰 적용한다.
종료 진행률은 각각 0.75 / 0.8이며, 목표까지 거리 제곱 280 Source 단위의 종료 조건도 적용한다(1 Source 단위 = 0.025m).
거리 기반 시간 압축이나 별도 초반 가속 곡선을 덧붙이지 않는다. 종료 시 몸이 아직 장애물에 걸쳐 있으면 남은 구간을 0.12초 동안 시작/종료 속도를 연결해 통과한다. 원본의 끝점 즉시 이동으로 생기던 카메라 전진 튐을 없애기 위한 의도적인 차이다. 취소/초기화/이동 중 장애물 출현 시 마지막으로 몸이 들어갈 수 있었던 위치로 복구한다.
Vault2 종료 속도는 원본의 200 Source 단위에 해당하는 5m/s이며, 넘던 경로의 수평 방향을 유지한다. 고개는 자유롭게 돌릴 수 있지만 뒤를 봤다고 종료 추진력이 역전되지 않는다. 같은 장애물 Collider에는 실제 착지 전까지 Vault/직접 Mantle로 재진입할 수 없다. 다른 장애물로의 공중 연계는 허용하며, 초기화/리스폰 시 기록을 지운다. 이는 뒤돌기로 같은 턱을 반복해서 넘는 문제를 막기 위한 원본과의 차이다. Vault1은 추가 수평 속도를 주지 않는다. 높은 렛지/봉 맨틀의 기존 운동량 처리는 유지한다.
FOV는 진입 속도를 사용해서 강제 이동 때문에 갑자기 확대되지 않는다. 낮은 Vault는 서 있는 눈높이를 유지하고, Vault2는 위쪽 피치, Vault1은 롤 방향으로 작은 일회성 카메라 충격을 준다. CameraEffectsPivot에서 감쇠 복귀하며 마우스 조준 회전을 덮어쓰지 않는다. Source 엔진 내부 ViewPunch와 동일한 구현은 아니다.
스텝 닷지는 30/60/120Hz에서도 마지막 프레임 이동량을 보정해 기본 2m를 유지한다. 벽 충돌이나 접지 상실로 중단하면 남은 스텝 무적도 취소한다. Q/E 무적과 성공 시 이동 규칙은 유지한다.
원본에서 호출하는 VManip/VMLegs 외부 애니메이션은 이 프로젝트에 포함되어 있지 않으므로 애니메이션까지 동일하게 재현한 것은 아니다.
기본 낙하 피해는 실제 낙하 높이 4m 초과 **그리고** 충돌 속도 16m/s 초과일 때만 발생한다. 초과 속도 1m/s당 피해 4다.
낮은 단차는 안전하며, 높은 낙하의 피해는 기존 착지 롤링으로 취소할 수 있다.
순간이동과 ResetVelocity는 특수 동작·회피·착지 기록을 정리한다.

## 적 공격 연결

현재 전투 관련 구현은 V 밀치기, 달리면서 V 태클, 공용 피해/체력/사망/회피 판정과 Phase 1 무기 사격·재장전이다. 사격 테스트 씬과 설정 방법은 [전투 제작 안내](CombatFoundationGuide.md)를 참고한다. 콤보·패링·적 AI는 아직 없다.

PlayerMovement가 시작할 때 PlayerDamageReceiver를 자동 연결/추가한다.
적의 실제 명중 판정이 성공했을 때 IDamageReceiver.ReceiveHit을 호출한다.
공격 ID는 공격 한 번에 하나를 발급하고, 그 공격의 여러 히트박스/접촉 콜백에서 공유한다.

```csharp
// 공격을 시작할 때 한 번 생성해 보관
long attackId = DamageHit.NewAttackId();

// 실제 Raycast / Overlap / 무기 충돌로 명중한 뒤 호출
var receiver = hitCollider.GetComponentInParent<IDamageReceiver>();
receiver?.ReceiveHit(new DamageHit(attackId, 15f, DamageKind.Attack,
    hitPoint, attackDirection, attackerGameObject));
```

공격이 실제 몸을 빗나갔다면 ReceiveHit을 호출하지 않는다. 경로를 스친 회피는 아래 전용 연결에서 처리하며, 회피 성공 이벤트를 Q/E 입력 시 직접 호출하면 안 된다.
DamageKind.Attack은 회피 무적으로 차단할 수 있지만 DamageKind.Fall은 차단하지 않는다. 낙하 피해 취소는 착지 롤링이 담당한다.
`HitResolved`와 `Died` 이벤트에 피격 효과·사망 UI·리스폰을 연결할 수 있다. 리스폰에서는 위치를 옮긴 뒤 `RestoreHealth()`를 호출한다.

무기 트리거 방식이라면 `AttackHitbox`를 사용할 수 있다. 트리거 Collider와 참여 물체 중 하나의 Rigidbody를 설정하고,
애니메이션 이벤트에서 `BeginAttack()` / `EndAttack()`을 호출한다. 소유자(owner)를 지정하여 자신의 공격을 무시한다.
`AttackHitbox`는 활성 공격 Collider와 스텝 경로의 교차도 매 프레임 검사한다. 한 공격에 히트박스가 여러 개면 `BeginAttackWithId(attackId)`로 같은 ID를 전달한다.

히트스캔은 `AttackTrace.Raycast(hit, origin, direction, range)`를 사용하면 실제 피격과 경로 회피 인정을 함께 처리한다. 첫 고체 충돌점까지만 검사하므로 벽 뒤의 경로는 보상하지 않는다. 연습용 공격기는 이 API로 연결했다.
별도 발사체는 기존 몸 명중 API와 함께 `StepDodgeTrail.RecognizeAttackSegment(hit, previousPosition, clippedEnd)`를 호출할 수 있다. `clippedEnd`는 반드시 실제 벽/대상 충돌로 잘린 이동 구간의 끝이어야 한다. 별도 적 AI나 무기 애니메이션은 제공하지 않는다.

밀치기를 받는 캐릭터는 `IShoveReceiver`, 피해를 받는 대상은 `IDamageReceiver`를 구현한다.
동적 Rigidbody만 있는 물체는 힘을 받는다. 전방의 첫 고체가 뒤의 대상을 가리므로 벽을 통과해 밀치지 않는다.

## 스윙 바 배치

1. 봉 중심에 빈 오브젝트를 만들고 `SwingBar`를 추가한다.
2. 로컬 X축을 봉의 길이 방향, 로컬 Z축을 스윙 진행 방향으로 놓는다.
3. `Grip Width`는 잡을 수 있는 구간, `Hang Length`는 손잡이부터 캐릭터 발 기준점까지의 길이로 설정한다.
4. 실제 봉 메시/Collider는 이 오브젝트의 자식으로 둔다. 캡슐이 스윙할 공간을 확보한다.
5. 봉 위 맨틀도 허용하려면 손잡이 위치에서 위로 올라설 수 있는 고체 Collider를 둔다. 봉 위와 옆에 몸이 통과할 공간이 필요하다.

초기 구현은 수평 봉을 기준으로 한다. 가까운 유효한 봉을 잡으며, 방금 놓은 봉에는 0.45초 동안 재부착하지 않는다.
다음 봉으로의 연결은 허용한다. 봉이 제거되거나 스윙 경로가 막히면 연결을 해제한다.

없거나 새로 만들고 싶다면 **Tools → Movement → Create Ability Playground**를 실행한다.
프로젝트의 기존 Player 액션 에셋이 프로젝트 전체 입력 에셋으로 지정되어 있어야 한다.

연습 씬에는 낮은 계단, Vault 난간, Mantle 단차, 클라이밍 벽, 봉 3개, 밀치기 대상과 회피 연습용 공격기가 있다.
공격기가 노란색이 되면 조준을 고정하고 0.4초 뒤 공격한다. Q/E를 너무 일찍 누르면 무적이 공격 전에 끝난다.
플레이어가 죽으면 Play Mode를 재시작하거나 RestoreHealth를 연결한 리스폰을 사용한다.

- **Tools → Movement → Run Refactor Checks**: 기존 이동 검증.
- **Tools → Movement → Run Ability Checks**: 새 기능 검증.

검사는 Play Mode 밖에서 임시 additive 씬을 사용한다. 이름 없는 새 씬이라면 먼저 저장해야 한다.
공유 무적, Q/E 입력만으로 이동하지 않음, 성공 시 단일 이동, 벽 충돌, 피해 중복, Vault/Mantle 실이동,
월 킥·벽 시간 제한, 봉 연결·소멸, 롤링, 밀치기/태클, 입력 바인딩과 리셋을 검사한다.
성공 즉시 스텝/마이크로 연속 회피, 같은 공격의 중복 보상 방지, 실제 이동 경로의 근접·사격 판정, 패딩 범위, 벽 차폐, 만료/초기화도 검사한다.

애니메이션 클립 없이 동작하는 이동/판정 구현이다. 손으로 봉을 잡는 애니메이션, 롤링 모델 애니메이션,
적 전용 피격 연출과 최종 조작감은 프로젝트 아트/전투 시스템에 맞춰 연결·조정할 수 있다.

## 화면 연출과 보조 기능

- 마우스 감도·Y 반전·상하 시점 제한, Esc 커서 해제와 좌클릭 재잠금.
- 실제 이동에 따른 헤드밥, 이동/다이브 롤, Q/E 기울이기, 속도 FOV, 착지 충격 완화, 앉기·슬라이드·포복별 카메라 높이.
- PlayerDamageReceiver의 체력·사망 이벤트, 순간이동 시 이동/낙하/회피 기록 초기화, 연습용 표적·사격기와 이동 디버그 HUD.
- 월 런은 삭제했다. 월 클라이밍·월 킥·렛지 대기/이동/도약은 유지한다. 별도 스태미나 시스템은 없다.

### 슬라이딩 점프와 다이브 속도 유지 조정

PlayerMovement 인스펙터의 Sliding Physics에서 Slide Jump Min Speed(3), Slide Jump Speed Bonus(0.8)를 조정한다. Diving In-Air Flight Physics의 Dive Speed Hold Duration(0.25)은 0.2~0.5초 범위에서 조정한다. 유지 시간은 공중 수평 감속에만 적용되며 중력, 충돌, 착지를 지연시키지 않는다. 0.25초는 우선 적용한 값으로 실제 플레이 감각에 따라 조정할 수 있다. PlayerLook의 Wall Climb Yaw Limit(30)은 클라이밍 시 한쪽 시야 제한 각도다.
