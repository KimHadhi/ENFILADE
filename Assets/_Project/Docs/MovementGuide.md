# 이동·회피·파쿠르 안내

[프로젝트 안내](../../../README.md) · [전투 안내](CombatFoundationGuide.md) · [이동 코드 구조](../Scripts/Player/Movement/README.md)

현재 조작은 [Player.inputactions](../Input/Player.inputactions)를 기준으로 합니다. 아래 수치는 **코드 기본값**이며, 실제 플레이에는 씬의 PlayerMovement 인스펙터 값이 우선합니다. 기능을 시험할 때는 [CombatFoundation](../Scenes/Development/CombatFoundation.unity) 또는 [MovementAbilityPlayground](../Scenes/Development/MovementAbilityPlayground.unity)를 사용합니다.

## 기본 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 조작 |
| Shift + 전진 | 달리기 |
| Space | 점프. 통과할 장애물이 있으면 Vault/Mantle 우선 |
| Ctrl 유지 | 앉기. 공중에서는 몸을 접어 캡슐 높이 축소 |
| 서서 이동 중 Z | 입력 방향으로 다이브. 뒤 입력은 누운 다이브 |
| 제자리 Z / 앉은 상태에서 Z | 포복 |
| 포복·누운 상태에서 Space | 공간이 있으면 먼저 일어나기 |
| 포복·누운 상태에서 Ctrl 또는 Z 재입력 | 가능한 앉기·서기 자세로 전환 |
| 포복·누운 상태에서 Shift + 이동 | 서 있을 공간이 있으면 빠르게 기상 |
| 달리는 중 Ctrl 새로 누르기 | 실제 속도가 충분하면 슬라이딩 |
| 슬라이딩 중 Alt | 가속과 저스트 슬라이드 판정 시작 |
| 지상에서 Alt + 방향 | 스텝 회피. 방향 입력이 없으면 뒤로 회피 |
| 지상에서 Q / E | 좌우 기울이기와 짧은 마이크로 회피 |
| 위험한 착지 직전 Ctrl 새로 누르기 | 조건을 만족하면 낙하 구르기 |

Alt는 좌우 Alt 모두 연결되어 있습니다. F 상호작용과 V 전투 동작은 [전투 안내](CombatFoundationGuide.md)에서 다룹니다.

걷기·달리기는 기본 5.2 / 8.4m/s, 앉기는 3m/s, 포복·누운 이동은 1.6m/s입니다. 점프 높이는 1.3m이며, 발판을 벗어난 직후 0.1초와 착지 직전 입력 0.15초를 보정합니다.

낮은 고정 천장 앞에서 앉아 이동하면, 포복 캡슐과 진입 경로가 비어 있을 때 자동으로 엎드립니다. 몸 전체가 통로를 빠져나오기 전에는 일어서지 않습니다. 정지한 누운 자세에서는 A/D와 S로 이동하고, W로 기상을 시도합니다. 누운 슬라이딩 중 W는 기상 입력으로 사용하지 않습니다.

## 슬라이딩과 저스트 슬라이드

### 진입·조향·종료

달리기와 전진을 유지한 채 Ctrl을 새로 누릅니다. 실제 이동 속도가 기본 5.3m/s 이상이어야 하므로, 벽에 막힌 채 달리기 키만 누르면 시작하지 않습니다.

A/D로 제한적으로 조향할 수 있습니다. 반대 방향을 입력하거나 Ctrl을 놓았다가 다시 누르면 제동합니다. 내리막은 가속하고 오르막은 감속하며, 기본 최대 슬라이딩 경사는 65도입니다. 감속 후에는 입력과 머리 공간에 맞춰 서기·앉기·포복으로 전환합니다.

일반 슬라이딩은 시작 0.1초 후 Space로 다이브 도약을 할 수 있습니다. 머리부터 미끄러지는 자세와 누운 슬라이딩에서는 이 점프를 사용하지 않습니다.

### 적과 접촉했을 때

슬라이딩 중 Alt를 새로 누르면 속력이 기본 **1.5m/s 증가**하고, 가속 시작부터 **0.18초** 동안 저스트 슬라이드 판정이 열립니다. 재사용 대기는 0.55초이며 키를 계속 누르는 것으로 반복 발동하지 않습니다. 이 가속에는 일반 회피의 무적이 붙지 않습니다.

적 크기는 적의 `MeleeCombatTarget → Body Size`에서 정합니다. 유효한 적에게 일반·저스트 슬라이딩 모두 기본 HP 피해 15를 한 번 전달합니다.

| 적 크기 | 일반 슬라이딩 | 저스트 슬라이드 중 접촉 |
| --- | --- | --- |
| 소형 | 적을 넘어뜨리고 통과. 접촉 순간 속력 90% 유지 | 적을 넘어뜨리고 통과. 접촉으로 인한 감속 없음 |
| 중형 | 적을 밀고 잠시 방해. 플레이어는 현재 슬라이딩 자세의 벽 충돌 반응 | 적을 넘어뜨리고 통과 |
| 대형 | 피해를 전달하되 밀지 않음. 플레이어는 현재 슬라이딩 자세의 벽 충돌 반응 | 적을 밀거나 넘어뜨리지 않고 플레이어가 회피처럼 통과 |

넘어짐·밀침은 대상이 실제 피해를 받은 경우 적용합니다. 한 번의 슬라이딩에서 같은 적을 여러 콜라이더로 만나거나 슬라이딩 자세가 바뀌어도 중복 피해를 주지 않습니다. 저스트 판정 중 통과한 적은 몸 밖으로 빠져나올 때까지 해당 적과의 몸 충돌만 잠시 무시합니다. 지면 마찰과 벽 충돌은 계속 적용됩니다.

### 벽 충돌과 레그돌

벽 반응은 기존 자세별 규칙을 유지합니다. 일반 슬라이딩은 충돌 속도에 따라 멈추거나 튕기며, 강한 반사는 누운 슬라이딩으로 이어질 수 있습니다. 비스듬한 접촉은 벽 방향으로 미끄러집니다. 머리부터·누운 슬라이딩의 정면 충돌은 해당 낮은 자세로 멈춥니다. 슬라이딩 공격은 태클의 피해나 히트스톱을 사용하지 않습니다.

적의 넘어짐은 실제 물리 반응입니다. 기본 넘어짐 시간은 1.2초입니다.

- 뼈대 레그돌이 없는 테스트 적은 몸통 Rigidbody와 콜라이더가 함께 쓰러집니다.
- 자식 Rigidbody와 Joint로 레그돌을 구성한 적은 뼈대 물리를 활성화합니다.
- 넘어지는 동안 Animator와 내비게이션을 멈추고 중력·회전 충격을 적용합니다. 바닥과 벽에 실제로 충돌합니다.
- 시간이 끝나도 발판이나 기립 공간이 없으면 쓰러진 상태를 유지합니다. 안전하게 설 수 있을 때 원래 본 자세·충돌체·Animator·내비게이션 상태를 복구합니다.

## 다이브

이동 중 Z로 도약합니다. 공중에서는 입력 방향으로 한 번 사용할 수 있으며, 입력이 없으면 전방을 사용합니다. 시선을 반대로 돌리면 전방/누운 자세를 바꿀 수 있지만, 추진력이나 체공 시간을 다시 얻지는 않습니다.

기본 수평 발사 속도는 9m/s입니다. 시작 0.25초 동안 속도를 유지한 뒤 부드럽게 감속하며, 착지하면 남은 운동량으로 머리부터·누운 슬라이딩에 연결됩니다. 착지 직후 0.55초 동안 새 다이브를 제한합니다. 다이브 자체에는 회피 무적이나 성공 보상이 없으며, 실제 몸의 이동·높이 변화로 공격을 피합니다.

상승과 엎드리는 느낌을 조절할 때는 PlayerMovement의 다음 항목부터 확인합니다.

| 항목 | 조절하는 내용 |
| --- | --- |
| Ground Dive Launch Speed / Vertical Pop | 수평 추진과 실제 상승력 |
| Dive Pose Delay / Duration | 몸과 눈높이가 낮아지기 시작하는 시점 / 걸리는 시간 |
| Dive Speed Hold Duration / Burst Duration / Burst Braking | 추진 유지 시간과 이후 감속 |
| Dive Landing Recovery | 착지 후 재발동 대기 |
| Dive Slide Friction / Supine Slide Friction | 착지 뒤 미끄러짐의 감속 |

시점의 상승 느낌만 바꾸려면 Pose 값을 먼저 조정합니다. Vertical Pop은 체공 시간과 이동거리까지 바꿉니다. 충분한 속도로 `IBreakable` 문에 부딪힌 슬라이딩·다이브는 문을 부수고 일부 속력을 유지할 수 있습니다.

## 스텝 회피와 기울이기

일반 회피는 지상 서기·앉기에서 시작합니다. 슬라이딩의 Alt는 앞에서 설명한 저스트 슬라이드 가속으로 처리합니다.

| 기능 | 코드 기본값과 규칙 |
| --- | --- |
| Alt 스텝 | 2.6m / 0.14초 이동. 공격 회피 판정은 처음 0.18초 |
| Q/E 마이크로 회피 | 입력 직후 0.08초 판정. 키 유지로 기울인 자세 유지 가능 |
| Q/E 성공 반응 | 실제 공격을 회피했을 때만 해당 방향으로 0.3m 이동 |
| 재사용 대기 | 실패 시 스텝 1.25초 / 마이크로 0.55초. 서로 같은 대기 상태를 공유 |
| 성공 후 연결 | 실제 회피 성공 시 대기를 초기화. 새 Alt/Q/E 입력으로 다음 회피 가능 |

Q/E 입력만으로 플레이어 몸이 옆으로 이동하지는 않습니다. 성공 반응은 짧게 가속·감속하며 진행되고, 벽에 막히면 가능한 거리까지만 움직입니다. 키를 놓아도 이동한 위치를 되돌리지 않습니다.

스텝은 실제로 이동한 경로에 회피 성공을 인정하는 영역을 남깁니다. 몸보다 기본 0.12m 넓고 무적 시간 동안만 유효합니다. 이 영역에 공격이 스치면 성공 보상만 주며, 피해를 받는 몸이나 물리 충돌체가 되지는 않습니다. 한 공격 ID는 몸과 경로를 통틀어 한 번만 처리합니다.

스텝 중과 마이크로 회피 판정 중에는 적의 몸을 통과할 수 있습니다. 종료 시 적과 겹쳐 있으면 벽·발판을 확인하며 안전한 출구를 찾습니다. 이 보정은 무적 시간을 늘리지 않습니다. Shift와 전진을 유지한 스텝이 정상적으로 끝나면 달리기를 이어갑니다.

## 파쿠르와 낙하

적의 몸과 자식 콜라이더는 벽 오르기·렛지 매달리기의 지지면으로 사용하지 않습니다. 매달린 채 적 쪽으로 옆 이동하는 것도 막습니다. 적 머리 위를 넘거나 올라서는 짧은 장애물 통과는 기존 조건대로 유지합니다.

| 상황 | 조작과 결과 |
| --- | --- |
| 지상의 낮은 장애물 | 이동 + Space로 Vault/Mantle. 경로가 막히면 일반 점프 |
| 공중의 장애물 | W로 접근하면 낮은 장애물 통과를 시도. 떨어지며 렛지에 접근하면 자동 잡기 |
| 렛지를 잡고 대기 | 벽을 본 상태에서 W를 놓았다가 다시 누르거나 Space로 올라가기 |
| 렛지 좌우 이동 | 벽을 향해 A/D. 가장자리 끝이나 막힌 옆 공간에서는 정지 |
| 렛지에서 방향 점프 | 벽 정면에서 기본 42도 넘게 시선을 돌린 뒤 Space |
| 렛지에서 내려오기 | Ctrl로 손 놓기 |
| 벽 오르기 | 공중에서 벽 정면을 향해 W + Space 유지로 진입 |
| 벽에서 튕기기 | 벽 오르기 중 Space를 놓았다가 다시 누르기 |
| 공중의 봉 | 가까이서 W 또는 Space로 잡기. 유효한 봉을 일반 장애물보다 먼저 선택 |
| 봉 스윙 | W/S로 가속·감속 |
| 봉에서 도약 | 방향 입력 + Space로 스윙 운동량을 이어서 도약 |
| 봉 위에 올라가기 | 방향 입력 없이 Space. 지지 콜라이더와 위쪽 공간 필요 |
| 봉에서 내려오기 | Ctrl로 도약 보너스 없이 손 놓기 |
| 위험한 착지 | 착지 전 0.22초 이내 Ctrl 새 입력과 구를 공간이 있으면 구르며 해당 낙하 피해 취소 |

Ctrl을 유지한 공중 이동은 자동 파쿠르 진입을 막습니다. 벽 오르기에 이미 진입한 뒤에는 W/Space를 놓거나 시선을 돌려도 즉시 취소되지 않습니다. 기본 벽 사용 시간은 공중에서 합계 1.8초이며, 다른 벽에 붙어도 새로 충전되지 않습니다. 정상 접지에서 회복합니다. 벽이 사라지거나 접촉·시간이 끝나면 이탈하고, 렛지에 도달하면 매달린 채 기다립니다. 벽을 옆으로 달리는 월 런은 구현되어 있지 않습니다.

낙하 피해는 기본적으로 충돌 직전 하강 속도 16m/s와 낙하 거리 4m를 모두 넘었을 때 발생합니다. 일반 회피 무적으로는 막지 못합니다. 다이브·포복·파쿠르 중이거나 기립·진행 공간이 부족하면 착지 구르기를 시작할 수 없습니다.

설정 변경 뒤에는 평지·경사·낮은 천장·벽 접촉을 함께 확인합니다. 저스트 슬라이드는 소형/중형/대형 각각에서 일반 접촉과 0.18초 안의 접촉을 비교하고, 벽 반응과 레그돌 기립도 확인합니다. 자동 검사 종류와 실행 조건은 [검증 안내](ValidationGuide.md)에 모았습니다.
