# 무기 슬롯·획득·진화 기획

사용자가 2026-10-21에 정한 방향과 2026-10-22 플레이 피드백을 반영했다. 이후 무기 시스템을 확장할 때 이 문서를 기준으로 한다.

## 슬롯 규칙 — 현재 구현

| 키 | 슬롯 유형 |
| --- | --- |
| 1 | 원거리 |
| 2 | 원거리 |
| 3 | 근접 |
| 4 | 특수 |

- 빈 슬롯도 선택 상태를 유지하며 기본 주먹을 사용한다. 주먹은 슬롯에 저장된 무기 아이템이 아니다.
- 같은 숫자를 다시 누르면 슬롯을 해제한다(`SelectedSlot = -1`). 이 상태에서는 총과 주먹 모델을 모두 내리고 LMB/RMB 주먹 전투도 비활성화한다. 빈 슬롯을 선택한 상태와는 다르다. `startingSlot = 0`은 슬롯을 선택하지 않고 시작한다는 뜻이다.
- 숫자 입력과 `ToggleSlot`은 선택/해제를 토글한다. 코드의 `SelectSlot`은 명시한 슬롯을 선택하고, `SelectSlot(-1)`은 모두 해제한다.
- 각 무기의 탄약은 슬롯별로 독립적이며 전환해도 보존한다. 전환하면 진행 중인 장전·차징·가드를 취소한다.
- `WeaponData.Category`와 `PlayerWeaponSlots.IsCompatible/TrySetWeapon`으로 슬롯 유형을 검사한다. 기존 총기 데이터의 기본 유형은 Ranged다.
- `TryAcquire`는 호환되는 빈 슬롯을 먼저 찾는다. 빈 슬롯이 없으면 현재 선택된 호환 슬롯만 교체하며, 밀려난 데이터를 호출자에게 돌려준다. 원거리 슬롯이 가득 찬 상태에서 3번을 선택하고 원거리 무기를 주워 교체하는 것은 불가능하다.
- 실제 필드 아이템, 드롭·상호작용 연출, 새 무기 데이터는 이번 구현 범위에 포함하지 않는다.

## 주먹 근접 전투 — 현재 구현

- LMB: 누르면 차징, 놓으면 한 번 타격. 기본 최대 차징 0.9초, HP 피해 10→28, 체간 피해 10→30. 접지 상태에서 짧은 전진 보정(0.12m)을 적용한다.
- RMB: 전방 120도 일반 근접 공격을 가드. 누른 뒤 0.18초 이내 첫 공격은 패링으로 체간 25 피해와 0.8초 기절을 준다. 같은 입력으로 패링 보상을 반복하지 않는다. 후방·낙하·방어 불가 공격과 총알은 방어하지 않는다.
- V Tap: 놓을 때 전방 120도·2.2m 범위를 밀친다. 범위 내 여러 적에게 각각 한 번씩 피해 3, 체간 8을 주고 공격 준비를 취소하며 0.85초 동안 경직시킨다. 앞의 적이 뒤의 적을 가리지 않으며 벽 뒤·후방·범위 밖 대상은 맞지 않는다. 한 적의 여러 충돌체에 중복 적중하지 않는다. NavMesh 적은 초기 속도 8m/s에서 0.32초 동안 감속하며 약 1.28m 밀린 뒤 남은 시간 동안 비틀거리며 행동할 수 없다. 벽과 이동 영역 경계에서 밀림을 제한한다. 물리 오브젝트는 충격량을 받는다.
- V Hold: 0.14초 이상 누르면 시야 앞 근거리의 적 한 명을 확보한다. 접근 속도는 12m/s이며, 실제 타격 거리 안에 들어오면 최소 0.04초 후 바로 체간 55 피해와 1.4초 기절을 준다. 접근 제한 시간은 0.24초, 타격 후 플레이어 회복 시간은 0.16초다. 가까운 적에게도 고정된 접근 시간을 기다리던 방식을 제거했다. 시전 중 이동·시점·공격·가드·회피·슬롯 교체를 잠근다. 벽, 대상 소멸, 범위 이탈, 접지 상실, 채팅·포커스 상실 시 취소한다. 길게 누른 뒤 놓을 때 밀치기를 추가로 발동하지 않는다.
- 총을 든 밀치기도 동일한 다중 대상 판정·밀림·0.85초 경직을 사용한다. 기본 HP 피해는 5, 체간 피해는 8이다. 달리면서 사용하는 태클은 기존 별도 판정을 유지하며 체간 20과 0.45초 경직을 적용한다.
- 밀치기 범위·각도·힘·경직은 플레이어의 `Ability Settings → Crowd Shove`에서 조절한다. `Shove Sweep Reach` 2.2, `Shove Sweep Angle` 120, `Shove Push Speed` 8, `Shove Stun` 0.85가 기본값이다. V 홀드 가드 브레이크는 계속 한 명을 붙잡는 기술이다.
- 주먹/총 밀치기가 적에게 적중하면 사용자 제공 `rifle_swing_hit_infected7~12.wav` 중 하나를 무작위 재생하며 바로 직전 소리는 피한다. 적을 맞히지 않고 벽·일반 물체에 닿으면 `rifle_swing_hit_world.wav`, 허공이면 타격음이 없다. 한 번의 밀치기에서 여러 적과 벽을 함께 맞혀도 적 타격음 한 번만 재생한다. `Assets/Resources/Combat/Feedback`의 `Shove Enemy Volume`, `Shove World Volume`에서 음량을 각각 조절하며 기본값은 모두 0.3이다.
- Q/E: 기존 기울이기와 마이크로 닷지를 유지한다. 가드 브레이크 시전 중에는 차단한다.
- 새 근접 무기는 만들지 않았다. 주먹 표시는 임시 절차적 장갑 메쉬이며 최종 애니메이션·모델은 이후 교체한다.
- `MeleeCombatTarget`은 체간, 회복, 기절, 단일 대상 확보를 담당한다. 체간 0은 별도의 `IsStaggered` 상태를 켜며, 체간을 모두 회복하기 전까지 `IsStunned`를 유지한다. 아래 흐트러짐·처형 규칙을 따른다.
- 기존 슬롯 HUD는 실행 시 4행으로 확장된다. 모든 행에 유형 이름을 유지하고 빈 슬롯은 `RANGED / ·`, `MELEE / ·`, `SPECIAL / ·`로 표시한다. 아이콘은 작은 가로선이며 FISTS 이름이나 주먹 아이콘을 쓰지 않는다. 슬롯을 해제하면 선택 강조와 오른쪽 아래 무기 표시만 없어진다. 편집기에서 영구 반영할 때는 `Tools → HUD → Install Weapon Slots`를 사용한다.
- 적과 연습 표적 위에 빨간 HP 바와 노란 체간 바를 표시한다. 체간은 남은 수치를 표시하므로 공격받으면 줄어든다. 최대 30m 이내의 화면에 보이는 대상만 표시하고, 벽 뒤·화면 밖·사망한 대상은 숨긴다. `EnemyVitalsHUD`는 실행 시 연결되어 기존 씬/프리팹에도 별도 설치 없이 적용된다.

## 흐트러짐과 처형 — 현재 구현

- 체간 0이 되는 순간 사용자 제공 사운드를 한 번 재생하고 적 몸 중앙에 큰 흐트러짐 이미지를 팝업한다. HP·체간 바는 머리 위에 유지한다. 몸 중앙에 투영하되 모델 앞에 그려서 이미지가 몸속에 가려지지 않도록 한다. 원본 이미지는 확장자와 달리 WebP였으므로 픽셀·투명도를 유지해 Unity용 PNG로 변환했다. 원본 파일은 변경하지 않는다.
- `Assets/Resources/Combat/Feedback`의 Inspector에서 `Stagger Sound Volume`(0~1, 기본 0.25)과 `Stagger Image Width`(기본 260)를 조절한다. 기존 음량은 0.8, 이미지 폭은 150이었다.
- 흐트러짐 이미지 폭은 3m 거리를 기준으로 하며, 가까워질수록 커지고 멀어질수록 거리에 반비례해 작아진다. 초근접 확대는 최대 2배로 제한한다. 크기 계산에는 모델 앞에 띄운 캔버스 위치가 아닌 적 몸 중앙까지의 실제 거리를 사용한다.
- 0.35초 후부터 4초 동안 체간을 전부 회복한다. 조금 회복되어도 행동 불가·처형 가능 상태는 계속된다. 추가 체간 공격은 회복 시간을 초기화하거나 효과음을 반복하지 않는다. Inspector에서 흐트러짐 회복 시간을 조절한다.
- `PlayerExecution`은 플레이어 초기화 시 자동 연결된다. 시야 중심에서 38도 이내, 대상 충돌체에서 2.1m 이내이며 벽에 가리지 않은 흐트러진 적 한 명을 선택한다. 슬롯 해제 상태에서도 가능하다. `Player/Interact` 바인딩(F)을 사용하며 다른 F 상호작용보다 먼저 처리한다.
- 크로스헤어 아래 붉은 배경과 `[F] 처형하기`를 표시한다. 1.32배 크기에서 0.2초 동안 원래 크기로 줄어들고, 범위 이탈·회복·사망 시 사라진다. 프로젝트의 한국어 폰트를 직접 참조한다.
- 임시 처형 구간은 0.8초, 즉사 타격 시점은 0.35초다. 기존 피해·사망 경로를 사용하므로 적의 사망 이벤트와 웨이브 처치 집계가 유지된다. 모델 애니메이션은 없으며 `Started`, `Impact`, `Ended` 이벤트에 연결할 수 있다.
- 처형 전체 구간에서 HP·실드를 보호하며 회피 보상은 주지 않는다. 이동·시점·총/주먹 공격·장전·가드·회피·슬롯 전환을 잠근다. 즉사 타격 뒤의 회복 구간에도 보호를 유지한다.
- 같은 씬의 적은 공격 준비를 취소하고 추적/공격을 멈춘다. 가까운 정상 상태의 NavMesh 적은 플레이어를 바라보며 초당 2.8m 속도로 2.6m 밖까지 후퇴한다. 벽과 NavMesh 경계를 통과하지 않으며 흐트러짐·기절 중인 적은 후퇴도 하지 않는다. 종료 후 추적이 재개되고 새 공격 준비가 필요하다.
- 대상 체간 회복은 처형 예약 중 멈춘다. 타격 전 대상 소멸·비활성화, 플레이어 리셋·비활성화, 채팅·포커스 상실 시 취소하고 잠금을 해제한다. 일시정지는 처형 시간을 보존한다.
- 표시/사운드/폰트 참조는 `Assets/Resources/Combat/Feedback.asset`, 검사는 `WeaponSlotsMeleeChecks`에 있다. 새로운 적 AI도 `MeleeCombatTarget.IsStunned`와 `PlayerExecution.Suppresses`를 존중해야 한다.

## 획득과 궁극기 — 이후 구현할 확정 방향

1. 필드 무기는 유형에 맞는 빈 슬롯에 자동으로 들어가거나, 호환되는 현재 무기와 교체한다.
2. 빈 슬롯(주먹)을 선택한 상태에서 궁극기를 사용하면 잠깐 게임 시간을 멈춘다.
3. 해당 슬롯 유형에 맞는 무작위 하위 티어 무기 3개를 제시하고, 플레이어가 하나를 선택해 슬롯에 넣는다.
4. 무기를 든 상태에서 궁극기를 사용하면 해당 무기를 상위 티어로 한 단계 진화시킨다.
5. 최종 진화 상태에서는 더 진화하지 않고 그 무기의 고유 궁극기(특수 스킬·버프 등)를 사용한다.
6. 1티어 무기는 고유 Q/E 액티브가 없어 기존 기울이기·마이크로 닷지를 사용한다. 진화하면 Q/E가 무기별 스킬로 바뀔 수 있다. 카타나의 Q 찌르기, E 대시는 예시다.
7. 가드 브레이크는 기본 한 명에게만 적용한다. 이후 스킬로 주변 여러 적에게 기절이 확산되도록 확장할 수 있다.

랜덤 3지선다, 시간 정지 선택 UI, 티어/진화 경로, 고유 궁극기, 진화한 Q/E 스킬, 다중 대상 가드 브레이크는 현재 동작으로 구현하지 않는다. 기존 궁극기 게이지는 유지하며 이 기획을 연결할 후속 작업으로 둔다.

## 검증

`Tools → Combat → Run Four Slots and Fists Checks`는 별도의 임시 씬에서 슬롯 유형, 빈 슬롯 선택, 탄약 보존, 차징/놓기, 벽 차단, 가드/패링, V 탭/홀드, 단일 대상, 취소와 행동 잠금 해제를 검사한다.
기존 총기 검사는 `Run Foundation Checks`, 이동 검사는 `Tools → Movement → Run Refactor Checks`를 사용한다.

흐트러짐 회복·처형 예약과 취소·무적·HUD·적 공격 중단은 위 검사에 포함된다. 실제 NavMesh 후퇴는 편집 모드에서 에이전트가 활성화되지 않으므로 별도 격리 프로젝트에서 `-batchmode -executeMethod ExecutionCrowdPlayChecks.RunBatch`로 검사한다(`-quit` 없이 실행하며 완료 시 스스로 종료). 이 검사는 가까운 적의 후퇴, 벽 차단, 거리 확보 후 정지, 흐트러진 적의 이동 금지, 종료 후 이동 복구를 확인한다.
