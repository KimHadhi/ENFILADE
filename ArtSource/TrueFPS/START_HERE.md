# ENFILADE · Blender 애니메이션 작업실

이 폴더의 [START_ANIMATING.cmd](START_ANIMATING.cmd)를 더블클릭하면 Blender 4.5 LTS에서 [ENFILADE_TrueFPS_Start.blend](ENFILADE_TrueFPS_Start.blend)와 작업 버튼을 함께 연다.

기본 캐릭터는 게임에서 사용하는 카즈사다. 손·발 IK와 머리 카메라가 준비되어 있다. **프레임 선택 → 뼈 이동·회전 → 키 저장**을 반복한 뒤 FBX로 내보내면 된다.

`_Start` 파일에는 손목을 아래팔 방향에 맞추고 손가락을 살짝 구부린 기본 포즈가 들어 있다. 처음 열면 `enf_practice_reach` 예제의 1프레임이다. 휴머노이드 54개 뼈(손가락 30마디 포함)와 루트·손발 IK 손잡이를 모두 선택하고 키를 넣을 수 있다.

## 1. 처음 열었을 때

| 화면 | 하는 일 |
| --- | --- |
| 왼쪽 | 머리에 붙은 카메라로 동작 확인. 이 화면에서만 머리·머리카락을 숨긴다 |
| 오른쪽 | 캐릭터 전체와 조작 뼈. 여기에서 포즈를 만든다 |
| 아래 | **Action Editor**. 도프 시트의 한 모드로, 동작 이름과 키프레임을 편집한다 |
| 오른쪽 화면의 `N` → **True FPS** | 키 저장·포즈 초기화·새 동작·FBX 내보내기 |

처음에는 **Pose Mode**이며, 조작 뼈만 보인다. 모드가 바뀌었다면 오른쪽 화면 왼쪽 위에서 Pose Mode로 돌아온다. **Edit Mode에서 뼈 길이·기준 자세·이름·부모 관계를 바꾸지 않는다.**

작업을 시작할 때 `File → Save As`로 자신의 `.blend` 사본을 만든다. 이후 `Ctrl+S`는 작업 원본 저장이다. FBX 내보내기는 별도로 해야 한다. 다음 작업 때는 실행 파일로 Blender를 연 뒤 `Ctrl+O`로 저장한 사본을 열면 도구를 계속 사용할 수 있다.

## 2. 어떤 뼈를 움직이나?

`.L`은 **캐릭터의 왼쪽**, `.R`은 캐릭터의 오른쪽이다. 화면의 좌우와 다를 수 있다.

| 조작 뼈 | 조작 | 결과 |
| --- | --- | --- |
| `CTRL_hand.L / .R` | `G` 이동, `R` 회전 | 손 위치와 손목 방향. 팔꿈치는 IK가 따라온다 |
| `CTRL_foot.L / .R` | `G` 이동, `R` 회전 | 발 위치와 발목 방향. 무릎은 IK가 따라온다 |
| `CTRL_elbow.L / .R` | `G` 이동 | 팔꿈치가 굽을 방향을 정하는 마름모 손잡이 |
| `CTRL_knee.L / .R` | `G` 이동 | 무릎이 굽을 방향을 정하는 마름모 손잡이 |
| `Hips` | `G`, `R` | 골반 높이·기울기. 손발 손잡이는 제자리에 남는다 |
| `Spine`, `Chest`, `Upper Chest` | 주로 `R` | 허리와 상체의 굽힘·비틀기 |
| `Neck`, `HeadBone` | 주로 `R` | 목·머리. 왼쪽 카메라도 머리 움직임을 따른다 |
| `Left shoulder / Right shoulder` | 주로 `R` | 어깨 자세 |
| `Left arm / Right arm` | 해당 팔을 **FK**로 전환 후 `R` | 위팔 회전 |
| `Left elbow / Right elbow` | 해당 팔을 **FK**로 전환 후 `R` | 아래팔·팔꿈치 회전 |
| `Left wrist / Right wrist` | 해당 팔을 **FK**로 전환 후 `R` | 손목 회전 |
| `Left leg / Right leg` | 해당 다리를 **FK**로 전환 후 `R` | 허벅지 회전 |
| `Left knee / Right knee` | 해당 다리를 **FK**로 전환 후 `R` | 종아리·무릎 회전 |
| `Left ankle / Right ankle` | 해당 다리를 **FK**로 전환 후 `R` | 발목 회전 |
| `Left toe / Right toe` | `R` | 발가락·앞꿈치 각도 |
| `Center` | `G`, `R` | 몸과 IK 손잡이 전체를 함께 이동·회전 |

**손가락 30마디는 처음부터 보이며 바로 키를 넣을 수 있다.** `Thumb`, `IndexFinger`, `MiddleFinger`, `RingFinger`, `LittleFinger`의 각 마디를 클릭해 `R`로 구부린다. `R X X`, `R Y Y`, `R Z Z`로 로컬 축을 고를 수 있다. 손가락은 팔의 IK/FK 설정과 관계없이 직접 회전한다.

**팔·다리 직접 회전:** True FPS 패널에서 해당 팔/다리 줄의 **FK**를 누른 뒤 위팔·아래팔·허벅지·종아리 등의 뼈를 선택해 `R`로 회전한다. **손발 고정:** 같은 줄의 **IK**를 누른 뒤 `CTRL_hand` 또는 `CTRL_foot`를 `G`로 옮긴다. 전환 버튼은 현재 포즈를 맞추고 모드 키도 저장한다. 팔다리를 길이 방향으로 크게 비튼 FK 자세는 IK로 바꿀 때 중간 관절의 비틀림이 달라질 수 있다.

**Key All Controls**는 휴머노이드 54개 뼈·루트·IK 손잡이 총 63개 조작 뼈의 위치·회전·크기와 네 팔다리의 IK/FK 모드를 저장한다. FK로 회전시킨 허벅지·종아리·팔과 손가락도 모두 포함된다. 내보낼 때는 FK/IK 결과를 원본 뼈의 최종 키로 굽는다.

Bone Collections의 `03 Arms`, `04 Legs`, `05 Fingers`가 보이는 조작 뼈다. `07 Original auxiliary bones`, `08 IK mechanism`은 보조 계산용이다.

오른쪽 화면에서 휠은 확대·축소, 휠 버튼 드래그는 회전, `Shift+휠 버튼 드래그`는 화면 이동이다. 뼈를 클릭해 선택하고 `Shift+클릭`으로 여러 개를 선택한다.

- `G` 후 `X / Y / Z`: 해당 축으로 이동. `R` 후 축 키: 해당 축으로 회전. 숫자 입력으로 양을 지정할 수 있다.
- 축 키를 두 번 누르면 해당 뼈의 로컬 축을 사용한다. 기본 전방은 장면의 `-Y` 방향이다.
- 클릭 또는 `Enter`로 확정, `Esc`로 취소, `Ctrl+Z`로 되돌린다.
- 팔·다리가 닿을 수 없는 곳에 손발 손잡이를 두면 관절이 완전히 펴진다. 몸이나 손잡이를 가까이 옮긴다.
- 일반 포즈 작업에서는 뼈의 크기를 바꾸는 `S`를 사용하지 않는 편이 좋다.

## 3. 1초짜리 손 뻗기 바꿔 보기

1. 열려 있는 `enf_practice_reach`에서 `Space`를 눌러 재생한다. **1 준비 → 16 뻗기 → 31 돌아오기**가 이미 들어 있다.
2. 멈춘 뒤 **16프레임**으로 이동한다. 오른쪽에서 `CTRL_hand.R`을 선택하고 `G`, `Y`, `0.03`, `Enter` 순으로 눌러 손을 몸 쪽으로 3cm 당긴다.
3. **Key All Controls**를 누르고 다시 재생한다. 왼쪽 시점에서 손이 어디까지 나오는지 비교한다.

처음에는 가운데 포즈 하나만 바꿔도 된다. 다른 이름으로 저장해 두고, 익숙해지면 **New Action**으로 같은 기본 자세에서 시작한다.

### 빈 동작으로 같은 연습하기

1. **True FPS → New Action**을 누르고 이름을 `enf_reach`, 끝 프레임을 `31`로 정한다. 새 동작은 기본 포즈에서 시작한다.
2. 현재 프레임을 **1**로 놓고 **Key All Controls**를 누른다. 이 버튼은 손가락을 포함한 조작 뼈들의 위치·회전·크기를 현재 프레임에 기록한다.
3. 아래 프레임 눈금 또는 현재 프레임 숫자로 **16**에 간다.
4. 오른쪽에서 `CTRL_hand.L`을 선택한다. `G`로 손을 앞으로 조금 뻗고 `R`로 손바닥 방향을 맞춘다. 왼쪽 시점을 보며 조절한다.
5. **Key All Controls**를 누른다. 뼈를 움직인 것만으로는 키가 저장되지 않는다. 기본값은 자동 키 꺼짐이다.
6. **31**로 이동한다. 같은 손을 선택해 **Reset Selected**로 기본 위치로 되돌린 뒤 **Key All Controls**를 누른다.
7. `Space`로 재생·정지한다. 중간 자세가 어색하면 그 프레임에서 포즈를 고치고 다시 키를 저장한다.
8. `Ctrl+S`로 `.blend`를 저장한 뒤 아래 내보내기를 진행한다.

기본은 **30fps**다. 프레임 1에서 31까지의 시간 차이는 `(31−1)÷30 = 1초`, 1에서 61까지는 2초다. 시작·끝 프레임은 재생 범위이면서 내보내기 범위다.

**Reset Selected는 선택한 뼈의 자세를 되돌리는 버튼**이다. 기존 키프레임을 삭제하지 않는다. 초기화한 자세를 동작에 반영하려면 키를 다시 저장한다.

## 4. 도프 시트에서 타이밍 고치기

키 편집 단축키는 마우스를 **아래 Action Editor 위에 둔 상태**에서 사용한다.

| 조작 | 결과 |
| --- | --- |
| 키 클릭 / `B`로 영역 선택 | 편집할 키 선택 |
| `G` | 선택한 키를 다른 시간으로 이동 |
| `Shift+D` | 선택한 키 복제 후 이동 |
| `S` | 선택한 키들의 시간 간격 늘리기·줄이기 |
| `X` 또는 `Delete` | 선택한 키 삭제 |
| `Home` | 키 전체가 보이도록 맞추기 |

반복 동작은 시작 포즈의 **모든 키를 끝 프레임에 복제**해 연결한다. 예를 들어 1프레임 키를 골라 `Shift+D`, `30`, `Enter`로 31프레임에 복사한다. 관절 속도가 끝에서 갑자기 멈추면 Graph Editor에서 보간 곡선도 조절한다.

동작은 **Action 하나당 하나**다. 새 동작은 New Action으로 만들고, 기존 동작은 아래 Action 이름 옆의 목록에서 선택한다. 새로 만들 때 기존 Action은 저장 유지 표시(Fake User)가 켜져 보존된다. 다른 Action을 선택한 뒤에는 그 동작에 맞게 시작·끝 프레임도 확인한다.

## 5. FBX 내보내기

1. 내보낼 **Action 이름**과 **시작·끝 프레임**을 확인한다. 동작 이름은 `enf_reach`, `enf_idle`처럼 `enf_` 접두사를 권장한다.
2. **True FPS → Export Current Action**을 누른다.
3. 이 폴더 아래 `Exports`에 `enf_reach.fbx`처럼 저장한다. 반복 동작이면 파일 창의 **Loop in Unity**를 켠다. 폴더는 내보낼 때 자동으로 생성된다.

처음 내보낼 때는 같은 이름의 `.clips.csv` 설정 파일도 만들어진다. 기존 설정 파일은 보존하므로, 반복 여부 등을 나중에 바꿨다면 그 CSV도 직접 수정한다.

도구는 현재 범위를 프레임마다 계산해 **원본 371개 뼈의 애니메이션으로 굽는다.** IK 손잡이·계산용 뼈·카메라·배경·캐릭터 메시가 FBX에 섞이지 않는다. 다른 Action도 함께 내보내지 않는다. `.blend`에는 조작용 IK와 편집 가능한 키가 남는다.

## 6. Unity 게임에 넣기

1. FBX와 함께 생성된 `.clips.csv`를 `Assets/_Project/Art/Animations/Custom/`에 복사한다.
2. Unity에서 그 FBX 선택 → **Rig → Animation Type: Humanoid → Avatar Definition: Copy From Other Avatar**.
3. **Source**에 기존 카즈사 모델의 **KazusaBandAvatar**를 지정하고 Apply한다. 모델 위치는 `Assets/_Project/Art/Models/Characters/KazusaBand/KazusaBand.fbx`다. 애니메이션의 첫 자세로 새 Avatar를 만들지 않는다.
4. FBX 옆의 `enf_reach.clips.csv`를 확인한다. 없다면 다음 내용으로 만든다. `clip`은 파일 이름이 아니라 **Blender Action 이름**과 같아야 한다.

```csv
clip,loop,inPlace,inPlaceY,inPlaceYaw,yawOffset,cycleOffset,from,to
enf_reach,0,0,0,0,0,0,,
```

5. FBX를 Reimport하고 Animation 탭의 이름·재생·반복 설정을 확인한다. 반복 동작은 `loop`를 `1`로 바꾼다.
6. 클립은 몸 프로필에 자동 등록된다. 실제 상태에서 쓰려면 `Assets/_Project/Resources/Tables/Player.csv`의 해당 `Body.*` 행을 바꾼다. 예: 새 서기 동작을 만들었다면 `Body.idle`의 값 `mx_idle`을 `enf_idle`로 교체한다. 등록만으로 기존 동작이 바뀌지는 않는다.
7. 게임을 Play하고 1인칭과 **F5 전체 몸 보기**에서 확인한다. 다른 스킨에서도 사용할 동작이면 해당 스킨으로도 검사한다.

게임의 실제 이동은 코드가 담당하며 Animator Root Motion은 꺼져 있다. CSV의 `inPlace / inPlaceY / inPlaceYaw`가 **0이면 작성한 이동·높이·회전을 몸 자세에 보존**한다. `1`이면 각각 수평 이동·높이 이동·회전을 제거하는 설정이다. 기본 0에서 시작하고, 캐릭터가 게임 이동에 더해 앞으로 밀리면 해당 동작의 수평 이동을 검토한다. `yawOffset`은 기본 0이며 다른 에셋의 180을 그대로 복사하지 않는다.

## 7. 미리보기와 게임의 차이 / 문제 해결

- 왼쪽 카메라는 **작성한 머리 움직임 자체**를 보여 준다. 가로 FOV 90°, 16:9이며 눈 뼈 중간에서 앞으로 0.02 모델 단위에 있다. 게임은 마우스 시선, 시점 안정화, 상체·손발 IK 등을 추가한다. 선택된 행동의 머리 각도도 제한·완화하므로 최종 화면은 Unity에서 확인한다.
- 모델 원본의 눈높이는 약 1.37이고 게임은 서 있는 눈높이를 1.6m에 맞춰 크기를 조정한다. Blender의 위치 숫자를 그대로 게임 장애물 거리로 해석하지 않는다.
- 작업 화면은 형태 확인용 Solid 표시다. Unity의 lilToon 재질·조명·머리카락 물리 효과를 재현하지 않는다.
- **True FPS 탭이 안 보임 / 왼쪽 화면이 비어 있음:** 실행 파일로 다시 연다. `.blend`만 열었다면 **Scripting**에서 `START HERE - True FPS tools.py` 텍스트를 고르고, 텍스트 영역 위에서 `Alt+P`로 실행한다. 그다음 `ENFILADE - Animate` 작업 공간으로 돌아온다. 자동 스크립트 실행 보안 설정은 바꿀 필요가 없다.
- **머리 시점에서 벗어남:** 왼쪽 화면 위에서 숫자패드 `0`으로 카메라 보기로 돌아온다. 뼈 편집은 오른쪽에서 한다.
- **관절이 뒤집힘:** 팔꿈치·무릎 방향 손잡이를 관절의 올바른 쪽으로 옮긴다. 손발 목표를 몸에서 지나치게 멀리 두지 않는다.
- **프레임을 바꾸면 자세가 사라짐:** 포즈 변경 뒤 Key All Controls를 누르지 않은 경우다.
- **Unity에서 팔이나 진행 방향이 뒤집힘:** 먼저 Source Avatar가 기존 KazusaBandAvatar인지 확인한다. 원본 뼈의 Edit Mode 자세를 바꾸었다면 준비된 템플릿에서 새 작업을 시작한다.

원본 게임 FBX와 Unity 설정 파일은 이 작업 파일의 저장·내보내기로 변경되지 않는다.
