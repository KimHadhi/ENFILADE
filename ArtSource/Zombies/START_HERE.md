# ENFILADE 좀비 애니메이션 작업실

**있는 클립을 바탕으로 깔고 → 슬라이더로 변형하고 → 필요한 곳만 손으로 고친 뒤 → 슬롯을 골라 게임에 보낸다.** 동작을 처음부터 만들 필요가 없다. 보낸 클립은 Unity가 그 슬롯 목록에 알아서 넣고, 좀비마다 목록에서 하나씩 골라 쓴다(모든 PC에서 같게).

## 열기

[START_ZOMBIE_ANIMATION.cmd](START_ZOMBIE_ANIMATION.cmd)를 더블클릭한다. 블렌더가 [작업 파일](ENFILADE_Zombie_Animation.blend)을 열고 3D 뷰 오른쪽 사이드바(`N`)의 **Zombie** 탭에 도구가 뜬다.

- 왼쪽 뷰: 뼈를 숨긴 미리보기. 오른쪽 뷰: 뼈를 잡고 고치는 곳. 아래: 타임라인.
- 패널 맨 위 `Hoodie` / `Roadworker` / `Police`로 같은 동작을 다른 좀비 몸에서 본다.
- `Space` 재생·멈춤, `Ctrl+Z` 되돌리기, `Ctrl+S` 저장. 작업을 여러 개 하려면 `File → Save As`로 다른 이름의 .blend로 저장해 둔다.
- 블렌더가 다른 곳에 깔려 있으면 환경 변수 `BLENDER_EXE`에 blender.exe 경로를 넣는다. .blend를 직접 열었다면 위쪽 `Scripting` 탭의 `START HERE - Zombie tools.py`에서 `Alt+P`를 누르고 `ENFILADE - Animate` 탭으로 돌아온다.

## 1. 바탕 클립

**클립 불러오기**를 누르고 이름 일부(walk, sit, attack, idle…)를 친다.

| 목록 | 들어 있는 것 |
| --- | --- |
| 팩 | 산 Nephilite 좀비 팩의 88가지 동작. `In Place`와 `Root Motion` 두 벌이 있는데 어느 쪽이든 된다 |
| 게임 | 이미 게임에 보낸 우리 클립. 다시 불러와 고칠 수 있다 |
| 받은 파일 | `ArtSource/Zombies/Inbox`에 넣은 Mixamo 등의 파일([받는 법](Inbox/README.md)) |

다른 폴더의 FBX는 **파일에서 불러오기**. Synty 뼈대(팩, 우리 클립)는 그대로 옮기고, Mixamo처럼 다른 사람 뼈대는 뼈마다 방향을 맞춰 옮긴다.

- **제자리**(기본 켬): 앞으로 나아가는 거리를 뺀다. 게임에서는 좀비가 스스로 움직이니 켜 둔다.
- **좌우 반전**: 왼손 휘두르기를 오른손으로, 왼다리 절기를 오른다리로.
- **빠르기**: 1보다 크면 빠르고 짧아진다.
- 옵션을 바꾼 뒤에는 **같은 클립 다시 불러오기**. 이때 변형과 손질은 지워진다.

바탕은 잠겨 있어서 아래 단계에서 무엇을 해도 망가지지 않는다.

## 2. 변형

값을 바꾸고 **변형 적용**. **무작위**는 값을 아무렇게나 정해 바로 적용한다. 무작위를 몇 번 눌러 마음에 드는 것이 나올 때마다 4단계로 보내면 한 클립에서 걷기 여러 개가 나온다.

| 값 | 하는 일 |
| --- | --- |
| 몸 숙이기 | 등을 앞으로 굽힌다(도). 고개는 반쯤 앞을 본다 |
| 고개 옆으로 / 고개 떨굼 | 고개를 옆으로 꺾거나 아래로 떨군다(도) |
| 팔 앞으로 | 두 팔을 앞으로 뻗는다. 1이면 거의 다 |
| 왼팔·오른팔 늘어뜨리기 | 그 팔이 힘없이 축 늘어진다 |
| 왼다리·오른다리 뻣뻣하게 | 무릎을 덜 굽혀 다리를 끈다 |
| 경련 | 머리·어깨가 가끔 툭 꺾인다. `경련 씨앗`을 바꾸면 꺾이는 때와 곳이 바뀐다 |
| 움직임 크기 | 0보다 크면 원래 움직임을 과장하고, 작으면 줄인다 |

`변형 켜짐`을 눌러 끄고 켜며 비교한다. `값 0으로`는 변형을 모두 없앤다.

## 3. 손질 (사람만 할 수 있는 일)

타이밍, 연기, "이 좀비다운" 순간은 여기서 만든다.

1. 아래 타임라인에서 고칠 프레임으로 간다.
2. 오른쪽 뷰에서 뼈를 클릭하고 `R`로 돌린다. `R` 다음 `X`/`Y`/`Z`를 누르면 그 축으로만, `R`을 두 번 누르면 자유롭게 돈다. 골반(`Hips`)은 `G`로 옮길 수도 있다.
3. `I`를 누른다(또는 패널의 **고른 뼈 지금 자세 저장**).

저장한 프레임을 중심으로 앞뒤가 부드럽게 섞인다. 바꾸는 범위를 좁히려면 그 앞뒤 프레임에서 원래 자세 그대로 `I`를 한 번씩 더 누른다. 아래 도프 시트에서 키를 골라 `X`로 지우고 `G`로 옮겨 타이밍을 바꾼다.

- **손질 켜짐**을 눌러 끄고 켜며 비교한다. **손질 모두 지우기**는 손으로 고친 것만 지운다.
- 걷기·서 있기처럼 반복하는 동작을 고쳤다면 마지막에 **처음 자세를 끝에**, 그다음 **반복 이음새 확인**.
- 해 볼 만한 것: 휘두르기 직전의 짧은 멈칫, 고개를 갸웃하는 순간, 갈고리처럼 구부린 손가락, 걷다가 한 번 휘청, 냄새를 맡듯 고개를 드는 동작.

## 4. 게임에 보내기

슬롯과 이름(영문·숫자)을 정하고 **게임에 보내기**. 파일은 `Assets/_Project/Art/Animations/Zombies/<슬롯>/enf_<이름>.fbx`로 간다. Unity 창을 누르면 가져오면서 [ZombieLooks](../../Assets/_Project/Resources/Enemies/ZombieLooks.asset)의 그 슬롯 목록에 넣는다(콘솔에 `[ZombieClipFolders] ... added`).

| 슬롯 | 게임에서 나오는 때 |
| --- | --- |
| 걷기 Walk | 깨어 있는 좀비가 천천히 움직일 때 |
| 뛰기 Run | 쫓아올 때. 거의 늘 이것이 보인다 |
| 서 있기 Idle | 깨어 있지만 서 있을 때 |
| 평온하게 서 있기 CalmIdle | 아무도 못 본 조용한 좀비 |
| 경계하며 서 있기 AlertIdle | 무언가 보고 멈춰 둘러볼 때 |
| 수색하며 걷기 SearchWalk | 소리 난 곳으로 찾아갈 때 |
| 휘두르기 Attack | 공격. 손이 가장 앞으로 나간 순간에 맞는다 |
| 움찔 Flinch | 공격이 끊겼을 때(헤드샷, 패링) |
| 휘청 Stagger | 자세가 무너져 처형할 수 있을 때 |
| 알아챔 Notice | 조용하다가 무언가 알아챘을 때 |
| 깨어남 Rouse | 깨어나 달려들기 직전 |
| 기면서 휘두르기 CrawlAttack | 다리를 잃고 기면서 공격할 때 |
| 앉기·먹기 자세 CalmPose | 조용한 좀비의 절반쯤이 이 자세로 있다(`Tables/ZombieClips.csv`의 `poseShare`) |
| 그 자세에서 일어나기 | 위 자세로 있다가 알아채거나 깰 때. 자세와 **같은 이름**으로 보내야 짝이 된다 |

확인: [CombatFoundation](../../Assets/_Project/Scenes/Development/CombatFoundation.unity)을 Play하고 채팅에 `/spawn 10`(깨어 있는 좀비) 또는 `/spawn 10 calm`(조용한 좀비). 좀비마다 목록에서 골라 쓰므로 여러 마리를 불러야 내 클립이 보인다. 빼고 싶으면 그 FBX를 지우거나 ZombieLooks 목록에서 지운다.

## 블렌더 없이 바로 넣기

Mixamo에서 **With Skin**으로 받은 FBX를 슬롯 폴더(`Assets/_Project/Art/Animations/Zombies/Walk/` 등)에 그대로 넣어도 된다. 반복 여부는 폴더가 정하고, 목록에 자동으로 들어간다.

## 안 될 때

- **사람 뼈대로 읽을 수 없는 파일**: 뼈 이름이 낯선 리그다. Mixamo나 Synty 뼈대 파일을 쓴다.
- **불러왔는데 팔다리가 꼬였다**: Skin 없이 받은 Mixamo 파일이다. With Skin으로 다시 받거나 같은 폴더에 `폴더이름.tpose.fbx`를 둔다.
- **게임에서 안 보인다**: 그 슬롯이 나오는 상황인지 본다(예: Notice는 조용한 좀비만). Unity 콘솔에 `[ZombieClipFolders]` 줄이 있는지 본다. 메뉴 `Tools → Zombies → Refresh Clip Folders`로 다시 채울 수 있다.
