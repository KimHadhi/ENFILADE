# ENFILADE 좀비 애니메이션 작업실

**있는 클립을 바탕으로 깔고 → 슬라이더로 변형하고 → 필요한 곳만 손으로 고친 뒤 → 슬롯을 골라 게임에 보낸다.** 동작을 처음부터 만들 필요가 없다. 보낸 클립은 Unity가 그 슬롯 목록에 알아서 넣고, 좀비마다 목록에서 하나씩 골라 쓴다(모든 PC에서 같게).

## 열기

[START_ZOMBIE_ANIMATION.cmd](START_ZOMBIE_ANIMATION.cmd)를 더블클릭한다. 블렌더가 [작업 파일](ENFILADE_Zombie_Animation.blend)을 열고 3D 뷰 오른쪽 사이드바(`N`)의 **Zombie** 탭에 도구가 뜬다.

- 왼쪽 뷰: 뼈를 숨긴 미리보기. 오른쪽 뷰: 뼈를 잡고 고치는 곳. 아래: 타임라인.
- 패널 맨 위 `Hoodie` / `Roadworker` / `Police`로 같은 동작을 다른 좀비 몸에서 본다.
- `Space` 재생·멈춤, `Ctrl+Z` 되돌리기, `Ctrl+S` 저장. 작업을 여러 개 하려면 `File → Save As`로 다른 이름의 .blend로 저장해 둔다.
- 블렌더가 다른 곳에 깔려 있으면 환경 변수 `BLENDER_EXE`에 blender.exe 경로를 넣는다. .blend를 직접 열었다면 위쪽 `Scripting` 탭의 `START HERE - Zombie tools.py`에서 `Alt+P`를 누르고 `ENFILADE - Animate` 탭으로 돌아온다.

## 처음이라면 (30분 코스)

블렌더를 처음 켜는 사람 기준이다. 아래 다섯 개만 알면 된다. 나머지 단축키는 몰라도 된다.

| 할 일 | 방법 |
| --- | --- |
| 재생·멈춤 | `Space` |
| 원하는 프레임으로 가기 | 아래 타임라인을 클릭하거나 끌기 |
| 되돌리기 | `Ctrl+Z` (여러 번 눌러도 된다) |
| 화면 돌려 보기 | 오른쪽 뷰에서 마우스 가운데 버튼을 누른 채 끌기, 휠로 확대 |
| 저장 | `Ctrl+S` |

1. **10분**: 1단계에서 클립 하나를 불러오고, 2단계 **무작위**를 몇 번 눌러 `Space`로 본다. 마음에 들면 4단계로 보낸다. 블렌더 실력이 하나도 필요 없다.
2. **10분**: 3단계에서 **머리**를 고르고 **왼쪽**을 세 번 누른다. 그 프레임 앞뒤로 고개가 기울었다 돌아온다. 다른 프레임, 다른 부위로 해 본다.
3. **10분**: 마음에 안 들면 `Ctrl+Z`나 **이 부위 지우기**. 다 됐으면 보낸다.

### 막히기 쉬운 곳

- **뭘 눌렀는지 모르게 화면이 이상해졌다**: `Ctrl+Z`. 그래도 이상하면 블렌더를 저장하지 말고 끄고 다시 연다. 작업 파일은 git에 있어 망가져도 되돌릴 수 있다.
- **뼈를 못 고르겠다 / 엉뚱한 게 골라진다**: 뷰에서 클릭하지 말고 3단계의 부위 버튼을 쓴다.
- **방향이 헷갈린다**: 왼쪽·오른쪽은 늘 **좀비 기준**이다. 미리보기 화면에서는 좀비가 이쪽을 보고 있어 좀비의 왼쪽이 화면 오른쪽이다.
- **한 군데 고쳤는데 전체가 바뀌었다**: `섞는 길이`가 0이면 그렇게 된다. 6 정도로 둔다.
- **고친 게 사라졌다**: 3단계의 `자동 저장`이 켜져 있으면 뼈를 돌리는 순간 저장된다. 꺼져 있으면 `I`를 눌러야 저장된다.
- **로봇 같다**: 정상이다. 그 느낌은 사람 눈으로 고르는 게 제일 빠르다. 아래 "AI에게 맡길 것과 내가 할 것"을 본다.

### AI에게 맡길 것과 내가 할 것

| AI(Claude)가 하는 게 빠른 것 | 사람이 하는 게 나은 것 |
| --- | --- |
| 뼈대 옮기기, Unity 설정, 폴더·이름, 반복 이음새, 내보내기 | "이건 좀비 같다 / 아니다" 고르기 |
| 클립 수십 개를 한꺼번에 변형해서 만들기 | 게임에서 보고 어색한 곳 짚기 ("30프레임쯤 고개가 너무 빳빳해") |
| "고개 20도 더", "휘두르기 전 0.2초 멈칫" 같은 숫자로 말할 수 있는 고침 | 타이밍의 맛, 연기(멈칫하는 순간, 갸웃하는 고개) |
| 팩·Mixamo에서 슬롯에 맞는 클립 고르기, 높이·이동 거리 재기 | 직접 좀비 연기를 해서 휴대폰으로 찍기(영상 모션캡처의 원본) |

가장 능률 좋은 방법: **게임에서 보고 → 말로 어디가 이상한지 Claude에게 말하고 → Claude가 레시피를 고쳐 넣고 → 다시 본다.** 블렌더는 말로 설명하기 어려운 미세한 연기를 직접 잡고 싶을 때만 연다.

## 1. 바탕 클립

**클립 불러오기**를 누르고 이름 일부(walk, sit, attack, idle…)를 친다.

| 목록 | 들어 있는 것 |
| --- | --- |
| 팩 | 산 Nephilite 좀비 팩의 88가지 동작. `In Place`와 `Root Motion` 두 벌이 있는데 어느 쪽이든 된다 |
| 게임 | 이미 게임에 보낸 우리 클립. 다시 불러와 고칠 수 있다 |
| 받은 파일 | `ArtSource/Zombies/Inbox`에 넣은 Mixamo 등의 파일([받는 법](Inbox/README.md)) |

다른 폴더의 FBX는 **파일에서 불러오기**. Synty 뼈대(팩, 우리 클립)는 그대로 옮기고, Mixamo처럼 다른 사람 뼈대는 뼈마다 방향을 맞춰 옮긴다.

- **제자리**(기본 켬): 앞으로 나아가는 거리를 뺀다. 게임에서는 좀비가 스스로 움직이니 켜 둔다.
- **좌우 반전**: 왼손 휘두르기를 오른손으로, 왼다리 절기를 오른다리로.
- **빠르기**: 1보다 크면 빠르고 짧아진다.
- 옵션을 바꾼 뒤에는 **같은 클립 다시 불러오기**. 이때 변형과 손질은 지워진다.

바탕은 잠겨 있어서 아래 단계에서 무엇을 해도 망가지지 않는다.

## 2. 변형

값을 바꾸고 **변형 적용**. **무작위**는 값을 아무렇게나 정해 바로 적용한다. 무작위를 몇 번 눌러 마음에 드는 것이 나올 때마다 4단계로 보내면 한 클립에서 걷기 여러 개가 나온다.

| 값 | 하는 일 |
| --- | --- |
| 몸 숙이기 | 등을 앞으로 굽힌다(도). 고개는 반쯤 앞을 본다 |
| 고개 옆으로 / 고개 떨굼 | 고개를 옆으로 꺾거나 아래로 떨군다(도) |
| 팔 앞으로 | 두 팔을 앞으로 뻗는다. 1이면 거의 다 |
| 왼팔·오른팔 늘어뜨리기 | 그 팔이 힘없이 축 늘어진다 |
| 왼다리·오른다리 뻣뻣하게 | 무릎을 덜 굽혀 다리를 끈다 |
| 경련 | 머리·어깨가 가끔 툭 꺾인다. `경련 씨앗`을 바꾸면 꺾이는 때와 곳이 바뀐다 |
| 움직임 크기 | 0보다 크면 원래 움직임을 과장하고, 작으면 줄인다 |

`변형 켜짐`을 눌러 끄고 켜며 비교한다. `값 0으로`는 변형을 모두 없앤다.

## 3. 손질 (사람만 할 수 있는 일)

타이밍, 연기, "이 좀비다운" 순간은 여기서 만든다.

1. 아래 타임라인에서 고칠 프레임으로 간다.
2. **부위 버튼**(머리, 목, 가슴 … 왼위팔, 왼아래팔 … 오른발)을 누른다.
3. **방향 버튼**을 누른다. `앞으로`·`뒤로`·`위로`·`아래로`·`왼쪽`·`오른쪽`은 그 부위의 끝을 그쪽으로 `한 번에`만큼(기본 5°) 움직이고, `비틀기`는 부위를 제 길이를 축으로 돌린다. 여러 번 누르면 더 많이 간다.

누른 프레임을 중심으로 `섞는 길이`(기본 6프레임)에 걸쳐 부드럽게 들어갔다 빠진다. 길게 하면 천천히, 짧게 하면 툭 꺾인다.

- **반대쪽에 똑같이**: 왼팔에 한 것을 오른팔에도 거울처럼.
- **이 부위 지우기** / **이 프레임 전부 지우기** / **손질 모두 지우기**: 고친 것만 지운다. 바탕과 변형은 그대로다.
- **손질 켜짐**을 눌러 끄고 켜며 비교한다.
- `자동 저장`(기본 켬): 익숙해져서 뷰에서 직접 뼈를 클릭하고 `R`로 돌릴 때도 바로 저장된다. `R` 다음 `X`/`Y`/`Z`를 누르면 그 축으로만 돈다.
- 걷기·서 있기처럼 반복하는 동작을 처음이나 끝 근처에서 고쳤다면 마지막에 **처음 자세를 끝에**, 그다음 **반복 이음새 확인**.
- 해 볼 만한 것: 휘두르기 직전에 고개를 살짝 뒤로(예비 동작), 걷다가 한 번 고개를 툭 꺾기, 한쪽 팔만 늦게 따라오기, 갈고리처럼 구부린 손.

## 4. 게임에 보내기

슬롯과 이름(영문·숫자)을 정하고 **게임에 보내기**. 파일은 `Assets/_Project/Art/Animations/Zombies/<슬롯>/enf_<이름>.fbx`로 간다. Unity 창을 누르면 가져오면서 [ZombieLooks](../../Assets/_Project/Data/Resources/Enemies/ZombieLooks.asset)의 그 슬롯 목록에 넣는다(콘솔에 `[ZombieClipFolders] ... added`).

| 슬롯 | 게임에서 나오는 때 |
| --- | --- |
| 걷기 Walk | 깨어 있는 좀비가 천천히 움직일 때 |
| 뛰기 Run | 쫓아올 때. 거의 늘 이것이 보인다 |
| 서 있기 Idle | 깨어 있지만 서 있을 때 |
| 평온하게 서 있기 CalmIdle | 아무도 못 본 조용한 좀비 |
| 경계하며 서 있기 AlertIdle | 무언가 보고 멈춰 둘러볼 때 |
| 수색하며 걷기 SearchWalk | 소리 난 곳으로 찾아갈 때 |
| 휘두르기 Attack | 공격. 손이 가장 앞으로 나간 순간에 맞는다 |
| 움찔 Flinch | 공격이 끊겼을 때(헤드샷, 패링) |
| 휘청 Stagger | 자세가 무너져 처형할 수 있을 때 |
| 알아챔 Notice | 조용하다가 무언가 알아챘을 때 |
| 깨어남 Rouse | 깨어나 달려들기 직전 |
| 기면서 휘두르기 CrawlAttack | 다리를 잃고 기면서 공격할 때 |
| 앉기·먹기 자세 CalmPose | 조용한 좀비의 절반쯤이 이 자세로 있다(`Tables/ZombieClips.csv`의 `poseShare`) |
| 그 자세에서 일어나기 | 위 자세로 있다가 알아채거나 깰 때. 자세와 **같은 이름**으로 보내야 짝이 된다 |

확인: [CombatFoundation](../../Assets/_Project/Scenes/Development/CombatFoundation.unity)을 Play하고 채팅에 `/spawn 10`(깨어 있는 좀비) 또는 `/spawn 10 calm`(조용한 좀비). 좀비마다 목록에서 골라 쓰므로 여러 마리를 불러야 내 클립이 보인다. 빼고 싶으면 그 FBX를 지우거나 ZombieLooks 목록에서 지운다.

## Claude에게 맡기기 (레시피)

맨 아래 **레시피 (Claude에게 맡기기)**를 열고 **레시피로 저장**을 누르면 지금 클립이 `ArtSource/Zombies/Recipes/이름.json`으로 남는다. 바탕, 변형 값, 손질, 슬롯이 다 들어 있다.

그다음 Claude에게 말로 시키면 된다. 예: "Recipes의 limp_walk에서 30프레임쯤 고개를 더 떨구고 오른팔은 늘어뜨린 버전 두 개 만들어서 걷기에 넣어 줘". Claude가 레시피를 고치거나 새로 만들고 블렌더 창 없이 FBX까지 만들어 게임 폴더에 넣는다. 블렌더에서 **레시피 불러오기**를 누르면 Claude가 고친 것을 그대로 다시 열어 손볼 수 있다.

## 블렌더 없이 바로 넣기

Mixamo에서 **With Skin**으로 받은 FBX를 슬롯 폴더(`Assets/_Project/Art/Animations/Zombies/Walk/` 등)에 그대로 넣어도 된다. 반복 여부는 폴더가 정하고, 목록에 자동으로 들어간다.

## 다른 컴퓨터에서 (블렌더만)

블렌더 작업에는 Unity가 필요 없다. 그 PC에 **Git for Windows**(Git LFS가 들어 있다), **Blender 4.5 LTS**(blender.org, 무료), GitHub 로그인만 있으면 된다. 먼저 이 PC의 작업이 GitHub에 올라가 있어야 한다.

처음 한 번, PowerShell에서 블렌더 작업에 쓰는 큰 파일만 받는다(약 150MB). 저장소를 통째로 받으면 큰 파일이 약 5GB라서 GitHub 무료 한도인 한 달 다운로드 10GiB의 절반을 한 번에 쓴다.

```powershell
$env:GIT_LFS_SKIP_SMUDGE = "1"
git clone -b multiplayer https://github.com/KimHadhi/ENFILADE.git
cd ENFILADE
git config lfs.fetchinclude "ArtSource/Zombies/**,Assets/ThirdParty/Nephilite Studios/**,Assets/_Project/Art/Animations/Zombies/**"
Remove-Item Env:GIT_LFS_SKIP_SMUDGE
git lfs pull
```

그 뒤로는 `git pull`도 이 폴더들의 큰 파일만 받는다. 작업은 똑같이 [START_ZOMBIE_ANIMATION.cmd](START_ZOMBIE_ANIMATION.cmd)로 연다(블렌더 위치는 알아서 찾고, 못 찾으면 `BLENDER_EXE` 환경 변수에 blender.exe 경로를 넣는다). 게임에 보내기는 그 PC의 `Assets/_Project/Art/Animations/Zombies/<슬롯>/`에 파일을 만든다. 끝나면 올린다.

```powershell
git add ArtSource/Zombies/Recipes Assets/_Project/Art/Animations/Zombies
git commit -m "좀비 클립 추가"
git push
```

이 PC에서 Claude에게 "받아 줘"라고 하면 받아서 Unity가 슬롯 목록에 넣는다.

- 그 PC에서는 이 폴더를 Unity로 열지 않는다. 받지 않은 큰 파일은 빈 껍데기라서 Unity가 깨진 에셋으로 읽는다.
- 작업 파일(.blend)은 `File → Save As`로 다른 이름에 저장한다. 같은 .blend를 두 PC에서 고치면 git이 합치지 못한다.
- 총 손 모양(Grip Tuner)은 Unity 안의 도구라서 프로젝트 전체가 있는 PC에서만 된다.

## 안 될 때

- **사람 뼈대로 읽을 수 없는 파일**: 뼈 이름이 낯선 리그다. Mixamo나 Synty 뼈대 파일을 쓴다.
- **불러왔는데 팔다리가 꼬였다**: Skin 없이 받은 Mixamo 파일이다. With Skin으로 다시 받거나 같은 폴더에 `폴더이름.tpose.fbx`를 둔다.
- **게임에서 안 보인다**: 그 슬롯이 나오는 상황인지 본다(예: Notice는 조용한 좀비만). Unity 콘솔에 `[ZombieClipFolders]` 줄이 있는지 본다. 메뉴 `ENFILADE → 좀비 → 클립 폴더 다시 읽기`로 다시 채울 수 있다.
