# ENFILADE 걷기·달리기 작업실

**게임이 쓰는 걷기·달리기 9개가 카즈사 뼈대(True FPS 리그)에 1차 시안으로 들어 있다. 자세를 손보고 `Ctrl+S`로 저장하면 게임에 들어간다.** 시안은 원본을 프레임마다 옮긴 것이라 모든 프레임에 키가 있다. 한 프레임만 고치면 그 프레임이 튀므로, 시안은 잠긴 아래 층(`1 시안 (잠금)`)에 두고 손본 것은 그 위의 손질 층에 들어간다. 손질 키 하나가 걸음 전체에 부드럽게 퍼지고, 시안은 망가지지 않는다.

## 열기 (이것 하나)

[START_RUN_ANIMATION.cmd](START_RUN_ANIMATION.cmd)를 더블클릭한다. 블렌더 4.5가 [작업 파일](ENFILADE_Run_Animation.blend)을 열면 이미 다 준비되어 있다. 작업 파일이 없으면 먼저 게임의 클립으로 새로 만든다(몇 분).

- 마지막에 고치던 걸음이 불러와져 있고, 카즈사가 **포즈 모드**라 아무 뼈나 눌러 `R`로 돌리면 된다. **자동 키**가 켜져 있어 손질 층에 바로 들어간다.
- 아래 **도프 시트**에 내가 넣은 손질 키가 보인다(처음엔 비어 있다). 맨 위 **Summary**(요약) 줄은 모든 키를 모은 줄이다.
- 오른쪽 사이드바에 **달리기** 탭이 열려 있다(안 보이면 `N`). 옆 **True FPS** 탭에는 카즈사 뼈대 도구(IK/FK 등)가 있다.
- 왼쪽 뷰는 머리 카메라, 곧 게임의 1인칭 화면이다. 오른쪽 뷰는 몸 전체다.
- 카즈사 옆(1m 왼쪽)의 막대 뼈대는 원본 클립이다. 카즈사 크기로 줄여 같은 박자로 움직인다. 보기용이라 내보내지 않는다.
- `Space` 재생·멈춤, `Ctrl+Z` 되돌리기, `Ctrl+S` 저장하고 게임에 보내기. 걸음은 고리라서 끝 프레임이 첫 프레임과 같은 자세다.
- .blend를 직접 열면 도구가 켜지지 않으니 cmd로 다시 연다.

## 내가 하는 것 / 도구가 하는 것

| 내가 (사람만 할 수 있는 것) | 도구가 알아서 |
| --- | --- |
| 자세 고치기(버튼이나 직접 `R`) | 손질 층에 키가 들어감(자동 키) |
| 마음에 들 때 `Ctrl+S` | 고친 걸음만 게임에 보냄. 안 고친 걸음은 게임이 원래 클립을 계속 씀 |

## 1. 걸음 고르기

| 버튼 | 원래 클립 | 게임에서 쓰이는 때 |
| --- | --- | --- |
| 달리기 · 앞 | `mx_run` | 앞으로 3~5m/s. W를 누르고 처음 1~2초, 조준을 풀고 달릴 때 |
| 전력질주 · 앞 | `sprintfwd` (Beatrun) | 앞으로 5m/s 넘게. W를 2초 넘게 누르거나 Shift(7.9~8.9m/s) |
| 걷기 · 앞 | `mx_walk` | 출발·멈춤, 2m/s 아래 |
| 달리기 · 오른쪽·왼쪽 | `mx_strafe_run_right`·`left` | 옆으로 3m/s 안팎. 더 빠르면 골반이 가는 쪽으로 돌아(최대 70°) 앞 달리기가 대부분을 맡는다 |
| 달리기 · 뒤 | `mx_run_back` | 뒤로(최대 4.9m/s) |
| 걷기 · 오른쪽·왼쪽·뒤 | `mx_strafe_walk_*`·`mx_walk_back` | 느리게 옆·뒤로 |

총을 든 채 조준하며 걸을 때의 다리(MoCap Online `W1_*` 조준 걸음)는 여기 없다. 조준하지 않으면 총을 들어도 이 걸음들이 다리를 맡는다(상체와 총은 FPSAF).

## 2. 손보기

**걸음 전체를 한 번에** 바꾸는 버튼은 고른 걸음의 모든 프레임에 같이 들어가므로 고리가 그대로 이어진다.

- `상체 세우기`·`상체 숙이기`: 허리·가슴을 한 번에 `세우는 각도`(기본 2°)만큼. 게임의 달리기는 걷기보다 상체가 많이 숙여져 있다(아래 숫자).
- `팔 크게`·`팔 작게`: 위팔·아래팔이 흔들리는 폭을 `흔들기 배율`(기본 ×1.15)만큼.
- `무릎 더 들기`·`무릎 덜 들기`: 허벅지·무릎이 흔들리는 폭.
- `출렁임 줄이기`·`출렁임 늘리기`: 골반이 위아래로 오르내리는 폭. 1인칭 화면의 흔들림도 같이 줄어든다.
- `고개 덜 흔들기`: 목·머리의 끄덕임.
- `골반 덜 돌기`: 골반이 걸음마다 좌우로 도는 폭.

그 밖에는 고칠 프레임으로 가서 뷰에서 `G`(옮기기)·`R`(돌리기)로 직접 움직인다. 자동 키가 켜져 있고 손질 층에만 들어간다. True FPS 탭의 IK로 바꿔 발·손을 끌어도 된다.

- `손질 층 켜기/끄기`: 손본 것을 끄고 시안만 보며 비교한다. 지우지는 않는다.
- `고리 이음매 확인`: 첫 프레임과 끝 프레임의 차이. 손으로 키를 넣었다면 끝 프레임이 처음과 같아야 게임에서 걸음이 튀지 않는다. True FPS 탭의 첫 프레임을 끝에 복사하는 버튼을 쓴다.
- `이 걸음 손질 모두 지우기`: 손질 층만 비운다. 시안은 그대로다.

**보폭과 박자는 게임이 맞춘다.** 게임은 몸이 생길 때 클립마다 발이 몸을 나르는 속도를 재고, 지금 속도에 맞춰 박자(분당 걸음)를 사람의 박자에 가깝게 바꾸고 남는 만큼 보폭을 늘린다. 그래서 여기서는 모양(자세·팔·무릎·고개)만 다듬으면 된다. 다리를 더 크게 휘두르면 그 클립이 나르는 속도가 올라가서, 빨리 달릴 때 게임이 덜 늘린다. 발이 미끄러지는지는 게임에서 콘솔 `/gait`로 본다.

## 3. 저장(`Ctrl+S`)하면 게임에 들어간다

`Ctrl+S`로 저장하면 지난번에 보낸 뒤로 고친 걸음만 게임에 보낸다. 화면 아래 상태줄에 「게임에 보냄: 달리기 · 앞」처럼 뜬다. 한 번도 고치지 않은 걸음은 보내지 않으므로 게임은 원래 클립을 그대로 쓴다.

| 가는 곳 | 게임에 들어가는 때 |
| --- | --- |
| `Assets/_Project/Art/Animations/Run/enf_<원래 클립>.fbx` (+ `.clips.csv`) | Unity 창을 누르면 카즈사 아바타로 가져간다. 다음 Play부터 `Player.csv`가 `<원래 클립>`을 적은 곳에 `enf_<원래 클립>`이 대신 쓰인다 |

- `Player.csv`는 고치지 않아도 된다. 마요·이치고·카즈사, 나중에 모드로 넣는 캐릭터 누구에게나 같은 걸음이 맞춰 붙는다.
- `원래 클립으로 되돌리기`: 보낸 파일을 지운다. 다음 Play부터 원래 클립이다. 그 걸음을 다시 고치면 저장할 때 다시 들어간다.
- 패널의 **게임에 보내기** 버튼은 `Ctrl+S`와 같다(고친 걸음을 보내고 작업 파일을 저장한다). **저장하면 게임에 보내기**를 끄면 `Ctrl+S`는 저장만 하고, 보낼 때는 이 버튼을 누른다.
- `손질 층 켜기/끄기`로 손질을 꺼 둔 채 저장해도 보낼 때는 손질이 들어간다.

## 잰 숫자 (2026-11-12, 블렌더로 잰 원본)

| 클립 | 원래 몸에서 나르는 속도 | 분당 걸음 | 걷기보다 상체가 숙여진 각도 |
| --- | --- | --- | --- |
| `mx_walk` | 1.5m/s | 124 | 0° |
| `mx_run` | 3.3m/s | 171 | 17° |
| `sprintfwd` | 4.2(작은 몸)·마요 5.6m/s | 240 | 25° |
| `mx_run_back` | 2.9m/s | 212 | 0° |
| `mx_strafe_run_*` | 3.0m/s | 180 | 14° |

사람의 달리기는 걷기보다 상체가 5~10° 더 숙여진다(전력질주 최고 속도에서도 10° 안팎). 게임 속도는 보통 4.9m/s, 오래 달리면 7.9~8.9m/s다.

## 막히기 쉬운 곳

- **시안이 원본과 다르다**: 옆의 원본 막대 뼈대와 비교한다. 다르면 손질 층에서 고친다.
- **처음부터 다시**: 작업 파일을 지우고 cmd를 다시 누르면 처음 시안으로 새로 만든다. 손본 것은 사라진다. 손본 뒤에는 `build_run_workspace.py --force`를 쓰지 않는다.
- **고친 게 게임에 안 나온다**: 저장했을 때 상태줄에 「게임에 보냄」이 떴는지, Unity 창을 누른 뒤 Play를 다시 시작했는지 본다.
